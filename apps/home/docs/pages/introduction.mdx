# WonDesign

WonDesign is a design system for React, built from four parts: Styling,
Interactions, Headless Components and Styled Components. Each part is a set of
small packages you can install on their own.

---

## How It Fits Together

Styling and Interactions are the base, and each part built on them decides a
little more for you. Pick the part that decides as much as you want.

- 🖌️ **[Styling](/styling)**: A CSS reset, design tokens and theme switching.
  They set the base of your app's look, and render nothing.
- 🧱 **[Interactions](/interactions)**: React hooks for focus, keyboard,
  pointer and positioning. They decide how things behave, but render nothing
  and take no stance on how anything looks.
- 🛠️ **[Headless Components](/headless)**: Accessible components built on
  Interactions, with state, keyboard support, focus and ARIA already wired up,
  and no styles at all. Bring your own look.
- 🎨 **[Styled Components](/components)**: Components with the WonDesign look,
  built on Headless Components and the tokens. Use them as they are, or
  arrange their parts into components of your own.

Alongside the layers, WonDesign has utilities for building a design system,
like [SVG2TSX](/svg2tsx), which turns SVG files into React icon components.

---

## Philosophy

<Callout title="Do the groundwork once">
  Every React app redoes the same groundwork, from a CSS reset to the same
  buttons and tooltips. WonDesign does it once, so you can focus on what makes
  your product **yours**.
</Callout>

<Callout title="Every package stands on its own">
  Install only the package you need, and it works. No other WonDesign package
  needs to be installed or set up first, not even the tokens.
</Callout>
