  `@wondesign/theme` is a small React layer that decides which theme the page

## Key Features

- ✅ **Named Themes**: Pick from a flat list of themes
- ✅ **Light and Dark**: Switch between light, dark and system, with one or more themes for each side
- ✅ **Follows the OS**: Can follow the user's OS light / dark setting, even when it changes
- ✅ **Persistence**: The user's choice is saved and re-applied on every visit
- ✅ **Cross-Tab Sync**: Change the theme in one tab, and every other open tab switches with it
- ✅ **No First-Paint Flash**: Prevents quick flashes on the very first paint
- ✅ **Hydration-Safe**: Works with server rendering, without hydration mismatch errors
- ✅ **Plain CSS Hooks**: Style each theme with plain CSS — no runtime styling needed

## Ways to Theme

There are three ways to theme your app, from the simplest to the most
flexible. Pick one per app.

- ⭐ **[Light-Dark](/styling/theme/setup#light-dark)** — a light / dark /
  system switch.
- ⭐ **[Advanced Light-Dark](/styling/theme/setup#advanced-light-dark)** —
  Light-Dark with more than one theme per side.
- ⭐ **[Named Themes](/styling/theme/setup#named-themes)** — a flat list
  of themes, none tied to light or dark.

---

## How It Works

The provider decides which theme is active. The user's choice comes first,
and your default applies until they make one. With Light-Dark in `"system"`
mode, the OS light / dark setting decides which side's theme is used.

The provider then writes the active theme to `<html>` as `data-theme`. With
Light-Dark, it also writes the side as `data-color-scheme`, and sets the
`color-scheme` style that `light-dark()` colors follow:

```html
<!-- Named Themes -->
<html data-theme="ocean"></html>

<!-- Light-Dark, with "midnight" picked for dark -->
<html
  data-theme="midnight"
  data-color-scheme="dark"
  style="color-scheme: dark"
></html>
```

The provider also saves the user's choices, and re-applies them on every
visit. With Light-Dark, that's the mode and the theme picked for each side.
With Named Themes, it's the theme. Apps on the same origin that both use
`@wondesign/theme` save to the same place by default, so **their choices
clash**. Give each app its own `storageKey` to keep them apart.

## Known Issues

- 🐞 **light-dark() colors in NextJS**: Colors built with `light-dark()` may not follow the theme, or fall back to an unexpected color, when your build tool rewrites `light-dark()` for older browsers. See [Styling](/styling#known-issues) for the fix
