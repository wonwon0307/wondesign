  `@wondesign/headless` is the behaviour layer under every styled WonDesign
  component. It handles state, keyboard support, focus and ARIA wiring, and
  renders plain elements with no styles at all — so you can build your own
  components on top of it, in your own look.

```bash
pnpm add @wondesign/headless
```

With [All-in-One](/all-in-one), import from `@wondesign/ui/headless` instead.

<Callout variant="warning" title="Requires React 19.2">
  `@wondesign/headless` needs React 19.2 or later.
</Callout>

## Key Features

- ✅ **Zero Styles**: Every component renders plain elements you style however you like
- ✅ **Accessible by Default**: Roles, ARIA attributes and keyboard support come built in
- ✅ **Controlled & Uncontrolled**: Stateful components work either way
- ✅ **Composable**: Swap the rendered element for your own with `asChild`
- ✅ **Styleable State**: Open, active, disabled and loading states are exposed as `data-*` attributes

## Components

The components come in three groups.

### Elements

Accessible wrappers around single native elements.

- 🔘 **[Button](/headless/button)** — a `<button>` with disabled and
  loading states that stays focusable while blocking clicks.
- 🔘 **[Anchor](/headless/anchor)** — an `<a>` that can be disabled,
  opens external links in a new tab, and works with router link components.

### Patterns

Multi-part components following the
[WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/patterns/).

- 🧩 **[Alert](/headless/alert)** — a modal alert that interrupts with
  an urgent message and waits for a response.
- 🧩 **[Collapsible](/headless/collapsible)** — a toggle that shows and
  hides a section of content.
- 🧩 **[Modal](/headless/modal)** — content on top of the page that
  blocks the page behind until the user is done.
- 🧩 **[Popover](/headless/popover)** — floating content opened from
  a trigger, that leaves the page behind usable.
- 🧩 **[Tabs](/headless/tabs)** — a set of tabs, each showing its own
  panel, with arrow-key navigation.
- 🧩 **[Toast](/headless/toast)** — a short message that's announced
  without interrupting and closes on its own.
- 🧩 **[Tooltip](/headless/tooltip)** — floating content shown on
  hover, focus or long press, positioned to stay on screen.

### Utilities

Helpers that control how and where things render. They don't render any UI of
their own.

- 🔧 **[AsChild](/headless/as-child)** — renders your own element in
  place of a component's default one, merging props, handlers and refs.
- 🔧 **[Portal](/headless/portal)** — renders its children at the end
  of `<body>`, safely with server rendering.
