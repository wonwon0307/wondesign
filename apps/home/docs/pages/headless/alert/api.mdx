# API

```ts
import {
  // compound component, with its parts attached
  Alert,
  // hook
  useAlert,
  // named exports
  AlertProvider,
  AlertTrigger,
  AlertBackdrop,
  AlertContent,
  AlertTitle,
  AlertMessage,
  AlertClose,
  // types
  type AlertProps,
  type AlertTriggerProps,
  type AlertBackdropProps,
  type AlertContentProps,
  type AlertTitleProps,
  type AlertMessageProps,
  type AlertCloseProps,
} from "@wondesign/headless/Alert";
// or from @wondesign/ui/headless
```

---

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### Provider

`Alert` or `AlertProvider`. Renders no element of its own.

**Props**

- 🔹 **isOpen**, **onOpenChange**: control the open state yourself. See
  [Open State](/headless/alert/usage#open-state).
- 🔹 **defaultOpen**: starts the alert open.
- 🔹 **keepMounted**: closed content is removed from the page by default. This
  hides it with the `hidden` attribute instead, so what's inside keeps its
  state. Watch out for
  [closed content that stays visible](/headless/alert/overview#watch-out).
- 🔹 **disablePortal**: renders the backdrop and content where they are in the
  DOM, instead of in a [Portal](/headless/portal) at the end of `<body>`.
  Watch out for
  [a backdrop and content that get clipped](/headless/alert/overview#watch-out).
- 🔹 **disableEscapeKey**: keeps the alert open on <Keyboard>Esc</Keyboard>,
  so only `Alert.Close` closes it.
- 🔹 **initialFocusRef**, **returnFocusRef**: the focus options. See
  [Focus Management](/headless/alert/usage#focus-management).

```ts
interface AlertProps {
  children: React.ReactNode;
  isOpen?: boolean;
  onOpenChange?: (open: boolean) => void;
  defaultOpen?: boolean; // defaults to `false`
  keepMounted?: boolean; // defaults to `false`
  disablePortal?: boolean; // defaults to `false`
  disableEscapeKey?: boolean; // defaults to `false`
  initialFocusRef?: React.RefObject<HTMLElement | null>;
  returnFocusRef?: React.RefObject<HTMLElement | null>;
}
```

### Trigger

`Alert.Trigger` or `AlertTrigger`. Renders a `<button>`, and accepts all props
of [Headless Button](/headless/button/api), except `type`, `aria-haspopup`
and `aria-controls`. Use it outside `Alert.Content` and `Alert.Backdrop`.
Inside either, **it only logs a warning** in development.

**Props**

- 🔹 **onClick**: runs before the alert opens. Call `event.preventDefault()`
  to keep it closed. See
  [Running an Action](/headless/alert/usage#running-an-action).

```ts
interface AlertTriggerProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Backdrop

`Alert.Backdrop` or `AlertBackdrop`. Renders a `<div>`, and accepts all its
props, except `hidden`. It **doesn't close the alert when clicked**. Wrap
`Alert.Content` with it, or use it as a sibling. Placing it inside
`Alert.Content` **only logs a warning** in development.

**Props**

- 🔹 **children**: the content, when the backdrop wraps it. See
  [Adding a Backdrop](/headless/alert/usage#adding-a-backdrop).

```ts
interface AlertBackdropProps {
  children?: React.ReactNode;
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
```

### Content

`Alert.Content` or `AlertContent`. Renders a `<div>` with the `alertdialog`
role, and accepts all its props, except `id`, `role`, `tabIndex`, `hidden`,
`aria-modal`, `aria-labelledby` and `aria-describedby`.

**Props**

- 🔹 **aria-label**: names the alert when it has no `Alert.Title`.

```ts
interface AlertContentProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  "aria-label"?: string; // defaults to `"Alert"`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
```

### Title

`Alert.Title` or `AlertTitle`. Renders an `<h2>` that names the alert, and
accepts all its props, except `id`. Must be used inside `Alert.Content`.

Without a title, the alert is named by the content's `aria-label`, so **a
title is strongly recommended**.

**Props**

```ts
interface AlertTitleProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  // ...
}
```

### Message

`Alert.Message` or `AlertMessage`. Renders a `<p>` that describes the alert,
and accepts all its props, except `id`. Must be used inside `Alert.Content`.

**Props**

```ts
interface AlertMessageProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  // ...
}
```

### Close

`Alert.Close` or `AlertClose`. Renders a `<button>`, and accepts all props of
[Headless Button](/headless/button/api), except `type`. Must be used inside
`Alert.Content`.

**Props**

- 🔹 **onClick**: runs before the alert closes. Call `event.preventDefault()`
  to keep it open. See
  [Running an Action](/headless/alert/usage#running-an-action).

```ts
interface AlertCloseProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  isLoading?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

## Hooks

### useAlert

Reads the state of the nearest `Alert`. Throws an error outside one.

```ts
function useAlert(): {
  isOpen: boolean; // whether the alert is open
  isPresent: boolean; // whether the alert is on the page, including while it animates out
  status: "open" | "closing" | "closed";
  showAlert: () => void; // opens it
  closeAlert: () => void; // closes it
  keepMounted: boolean; // the `keepMounted` prop
};
```
