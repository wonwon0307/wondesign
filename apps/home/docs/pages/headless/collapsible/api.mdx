# API

```ts
import {
  // compound component, with its parts attached
  Collapsible,
  // hook
  useCollapsible,
  // named exports
  CollapsibleProvider,
  CollapsibleToggle,
  CollapsibleContent,
  // types
  type CollapsibleProps,
  type CollapsibleToggleProps,
  type CollapsibleContentProps,
} from "@wondesign/headless/Collapsible";
// or from @wondesign/ui/headless
```

---

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### Provider

`Collapsible` or `CollapsibleProvider`. Renders no element of its own.

**Props**

- 🔹 **isOpen**, **onOpenChange**: control the open state yourself. See
  [Open State](/headless/collapsible/usage#open-state).
- 🔹 **defaultOpen**: starts the content open.
- 🔹 **keepMounted**: closed content is removed from the page by default. This
  hides it with the `hidden` attribute instead, so anything inside keeps its
  state. Watch out for
  [closed content that stays visible](/headless/collapsible/overview#watch-out).

```ts
interface CollapsibleProps {
  children: React.ReactNode;
  isOpen?: boolean;
  onOpenChange?: (open: boolean) => void;
  defaultOpen?: boolean; // defaults to `false`
  keepMounted?: boolean; // defaults to `false`
}
```

### Toggle

`Collapsible.Toggle` or `CollapsibleToggle`. Renders a `<button>`, and accepts
all props of [Headless Button](/headless/button/api), except `id`, `type`,
`aria-expanded` and `aria-controls`. Use it outside `Collapsible.Content`.
Inside it, **it only logs a warning** in development.

For a close button inside the content, build one with
[`useCollapsible`](/headless/collapsible/usage#custom-parts) instead.

**Props**

- 🔹 **onClick**: runs before the content opens or closes. Call
  `event.preventDefault()` to skip it. See
  [Running an Action](/headless/collapsible/usage#running-an-action).
- 🔹 **isDisabled**: stops the toggle from opening or closing the content. It
  stays focusable, and the content stays as it is.

```ts
interface CollapsibleToggleProps {
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  isLoading?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Content

`Collapsible.Content` or `CollapsibleContent`. Renders a `<div>`, and accepts
all its props, except `id`, `hidden`, `aria-hidden` and `aria-labelledby`.

**Props**

- 🔹 **role**: pass `"region"` when the content is a major section of the
  page, and it's labelled by its toggle.

```ts
interface CollapsibleContentProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  role?: "group" | "region"; // defaults to `"group"`, or none with `asChild`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
```

## Hooks

### useCollapsible

Reads the state of the nearest `Collapsible`. Throws an error outside one.

```ts
function useCollapsible(): {
  isOpen: boolean; // whether the content is open
  isPresent: boolean; // whether the content is on the page, including while it animates out
  status: "open" | "closing" | "closed";
  toggle: () => void; // opens or closes the content
  keepMounted: boolean; // the `keepMounted` prop
};
```
