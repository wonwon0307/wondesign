# API

```ts
import {
  // compound component, with its parts attached
  Tabs,
  // hooks
  useTabs,
  useTabsList,
  // named exports
  TabsProvider,
  TabsList,
  Tab,
  TabPanel,
  // types
  type TabsProps,
  type TabsListProps,
  type TabProps,
  type TabPanelProps,
} from "@wondesign/headless/Tabs";
// or from @wondesign/ui/headless
```

---

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### Provider

`Tabs` or `TabsProvider`. Renders no element of its own.

**Props**

- 🔹 **defaultTab**: the tab it starts on.
- 🔹 **selectedTab**, **onTabChange**: control the selected tab yourself. See
  [Selected Tab](/headless/tabs/usage#selected-tab).
- 🔹 **isDisabled**: disables every tab.
- 🔹 **switchOnFocus**: selects a tab as soon as it's focused, instead of on
  <Keyboard>Enter</Keyboard> or <Keyboard>Space</Keyboard>.
- 🔹 **keepMounted**: inactive panels are removed from the page by
  default. This hides them with the `hidden` attribute instead, so anything
  inside keeps its state. Watch out for
  [inactive panels that stay visible](/headless/tabs/overview#watch-out).

```ts
interface TabsProps {
  children: React.ReactNode;
  defaultTab?: string; // defaults to the first enabled tab
  selectedTab?: string;
  onTabChange?: (tab: string) => void;
  isDisabled?: boolean; // defaults to `false`
  switchOnFocus?: boolean; // defaults to `false`
  keepMounted?: boolean; // defaults to `false`
}
```

### List

`Tabs.List` or `TabsList`. Renders a `<div>`, and accepts all its props,
except `role` and `aria-orientation`. Label it with an `aria-label` or
`aria-labelledby`. See [Labelling the List](/headless/tabs/usage#labelling-the-list).

**Props**

- 🔹 **vertical**: <Keyboard>↑</Keyboard> and <Keyboard>↓</Keyboard> move
  between tabs, instead of <Keyboard>←</Keyboard> and <Keyboard>→</Keyboard>.
  It **doesn't change the layout**.
- 🔹 **loop**: the arrow keys wrap around from the last tab to the first,
  instead of stopping at the ends.

```ts
interface TabsListProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  vertical?: boolean; // defaults to `false`
  loop?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-orientation": "horizontal" | "vertical";
"data-disabled": "true" | undefined; // present when the tabs are disabled
```

### Tab

`Tabs.Tab` or `Tab`. Renders a `<button>`, and accepts all props of
[Headless Button](/headless/button/api), except `id`, `role`, `tabIndex`,
`onFocus`, `aria-selected`, `aria-controls` and `isLoading`. Must be used
inside `Tabs.List`.

**Props**

- 🔹 **tabName**: pairs the tab with the panel of the same `tabName`. It's the
  value you get from `onTabChange`, `useTabs` and `data-value`.
- 🔹 **onClick**: runs before the tab is selected. Call
  `event.preventDefault()` to keep the current tab. See
  [Running an Action](/headless/tabs/usage#running-an-action).
- 🔹 **isDisabled**: disables just this tab. Disabled tabs are **skipped by the
  arrow keys**.

```ts
interface TabProps {
  children: React.ReactNode;
  tabName: string;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "active" | "inactive";
"data-orientation": "horizontal" | "vertical";
"data-value": string; // the tab's `tabName`
"data-disabled": "true" | undefined; // present when disabled
```

### Panel

`Tabs.Panel` or `TabPanel`. Renders a `<div>`, and accepts all its props,
except `id`, `role`, `hidden`, `tabIndex` and `aria-labelledby`.

**Props**

- 🔹 **tabName**: pairs the panel with the tab of the same `tabName`. The panel
  is shown while that tab is selected.

```ts
interface TabPanelProps {
  children: React.ReactNode;
  tabName: string;
  asChild?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "active" | "inactive";
```

## Hooks

### useTabs

Reads the state of the nearest `Tabs`. Throws an error outside one.

```ts
function useTabs(): {
  activeTab: string; // the selected tab's `tabName`
  updateActiveTab: (tab: string) => void; // selects a tab
  isDisabled: boolean; // whether every tab is disabled
};
```

### useTabsList

Reads the state of the nearest `Tabs.List`. Throws an error outside one.

```ts
function useTabsList(): {
  orientation: "horizontal" | "vertical";
};
```
