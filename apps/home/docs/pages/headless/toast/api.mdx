import {

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### ToastArea

Renders a `<div>` with the `status` role as a polite live region, and accepts
all its props, except `role`, `aria-live` and `aria-atomic`.

**Props**

- 🔹 **disablePortal**: renders the area where it is in the DOM, instead of
  in a [Portal](/headless/portal) at the end of `<body>`. Watch out for
  [toasts that get clipped](/headless/toast/overview#watch-out).

```ts
interface ToastAreaProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  disablePortal?: boolean; // defaults to `false`
  // ...
}
```

### Toast

Renders a `<div>`, and accepts all its props, except `hidden`, `role`,
`aria-live`, `aria-atomic`, `onMouseEnter`, `onMouseLeave`, `onFocus` and
`onBlur`. It closes on <Keyboard>Esc</Keyboard> while focus is inside it.
Must be used inside `ToastArea`.

**Props**

- 🔹 **duration**: how long it stays open, in milliseconds. `0` keeps it open
  until it's closed. See [Duration](/headless/toast/usage#duration).
- 🔹 **isOpen**, **onOpenChange**: control the open state yourself.
  `onOpenChange` **is only called when `isOpen` is passed**. See
  [Open State](/headless/toast/usage#open-state).
- 🔹 **defaultOpen**: shows the toast as soon as it's rendered.

```ts
interface ToastProps {
  children: React.ReactNode;
  duration?: number; // defaults to `5000`
  isOpen?: boolean;
  onOpenChange?: (isOpen: boolean) => void;
  defaultOpen?: boolean; // defaults to `false`
  asChild?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-paused": "true" | undefined; // present while the timer is paused
```

### ToastMessage

Must be used inside `Toast`.

**Props**

interface ToastMessageProps {

### ToastDescription

Renders a `<p>` with optional detail, and accepts all its props. Must be used
inside `Toast`.

**Props**

```ts
interface ToastDescriptionProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  // ...
}
```

### ToastClose

Renders a `<button>`, and accepts all props of
[Headless Button](/headless/button/api), except `type`. Must be used inside
`Toast`.

Each toast is read as a whole, **including its close button's label**, so
pick one that makes sense after the message, like "Dismiss" or "Undo".

**Props**

- 🔹 **onClick**: runs before the toast closes. Call `event.preventDefault()`
  to keep it open. See
  [Running an Action](/headless/toast/usage#running-an-action).

```ts
interface ToastCloseProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

## Hooks

### useToast

Reads the state of the nearest `Toast`. Throws an error outside one.

```ts
function useToast(): {
  isOpen: boolean; // whether the toast is open
  isPaused: boolean; // whether the timer is paused
  isPresent: boolean; // whether the toast is on the page, including while it animates out
  status: "open" | "closing" | "closed";
  dismissToast: () => void; // closes it
  pauseTimer: () => void; // stops the timer
  resumeTimer: () => void; // continues the timer from where it stopped
};
```
