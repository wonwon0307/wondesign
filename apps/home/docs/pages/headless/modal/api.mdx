# API

```ts
import {
  // compound component, with its parts attached
  Modal,
  // hook
  useModal,
  // named exports
  ModalProvider,
  ModalTrigger,
  ModalBackdrop,
  ModalContent,
  ModalTitle,
  ModalClose,
  // types
  type ModalProps,
  type ModalTriggerProps,
  type ModalBackdropProps,
  type ModalContentProps,
  type ModalTitleProps,
  type ModalCloseProps,
} from "@wondesign/headless/Modal";
// or from @wondesign/ui/headless
```

---

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### Provider

`Modal` or `ModalProvider`. Renders no element of its own.

**Props**

- 🔹 **isOpen**, **onOpenChange**: control the open state yourself. See
  [Open State](/headless/modal/usage#open-state).
- 🔹 **defaultOpen**: starts the modal open.
- 🔹 **keepMounted**: closed content is removed from the page by default. This
  hides it with the `hidden` attribute instead, so what's inside keeps its
  state. Watch out for
  [closed content that stays visible](/headless/modal/overview#watch-out).
- 🔹 **disablePortal**: renders the backdrop and content where they are in the
  DOM, instead of in a [Portal](/headless/portal) at the end of `<body>`.
  Watch out for
  [a backdrop and content that get clipped](/headless/modal/overview#watch-out).
- 🔹 **disableOutsideClick**: keeps the modal open on a click outside the
  content, including on the backdrop.
- 🔹 **disableEscapeKey**: keeps the modal open on <Keyboard>Esc</Keyboard>.
- 🔹 **initialFocusRef**, **returnFocusRef**: the focus options. See
  [Focus Management](/headless/modal/usage#focus-management).

```ts
interface ModalProps {
  children: React.ReactNode;
  isOpen?: boolean;
  onOpenChange?: (open: boolean) => void;
  defaultOpen?: boolean; // defaults to `false`
  keepMounted?: boolean; // defaults to `false`
  disablePortal?: boolean; // defaults to `false`
  disableOutsideClick?: boolean; // defaults to `false`
  disableEscapeKey?: boolean; // defaults to `false`
  initialFocusRef?: React.RefObject<HTMLElement | null>;
  returnFocusRef?: React.RefObject<HTMLElement | null>;
}
```

### Trigger

`Modal.Trigger` or `ModalTrigger`. Renders a `<button>`, and accepts all props
of [Headless Button](/headless/button/api), except `type` and
`aria-haspopup`. Use it outside `Modal.Content` and `Modal.Backdrop`. Inside
either, **it only logs a warning** in development.

**Props**

- 🔹 **onClick**: runs before the modal opens. Call `event.preventDefault()`
  to keep it closed. See
  [Running an Action](/headless/modal/usage#running-an-action).

```ts
interface ModalTriggerProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Backdrop

`Modal.Backdrop` or `ModalBackdrop`. Renders a `<div>`, and accepts all its
props, except `hidden`. A click on it closes the modal, like any click outside
the content. Wrap `Modal.Content` with it, or use it as a sibling. Placing it
inside `Modal.Content` **only logs a warning** in development.

**Props**

- 🔹 **children**: the content, when the backdrop wraps it. See
  [Adding a Backdrop](/headless/modal/usage#adding-a-backdrop).

```ts
interface ModalBackdropProps {
  children?: React.ReactNode;
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
```

### Content

`Modal.Content` or `ModalContent`. Renders a `<dialog>` that acts as a modal
dialog, and accepts all standard HTML attributes, except `role`, `hidden`,
`tabIndex`, `aria-modal` and `aria-labelledby`.

It **doesn't accept `<dialog>`-only props**, like `open`, `onClose` or
`onCancel`. Use `isOpen` and `onOpenChange` on `Modal` instead.

**Props**

- 🔹 **aria-label**: names the modal when it has no `Modal.Title`.

```ts
interface ModalContentProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  "aria-label"?: string; // defaults to `"Modal"`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
```

### Title

`Modal.Title` or `ModalTitle`. Renders an `<h2>` that names the modal, and
accepts all its props, except `id`. Must be used inside `Modal.Content`.

Without a title, the modal is named by the content's `aria-label`, so **a
title or an `aria-label` of your own is strongly recommended**.

**Props**

```ts
interface ModalTitleProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  // ...
}
```

### Close

`Modal.Close` or `ModalClose`. Renders a `<button>`, and accepts all props of
[Headless Button](/headless/button/api). Must be used inside `Modal.Content`.

**Props**

- 🔹 **onClick**: runs before the modal closes. Call `event.preventDefault()`
  to keep it open. See
  [Running an Action](/headless/modal/usage#running-an-action).

```ts
interface ModalCloseProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  isLoading?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

## Hooks

### useModal

Reads the state of the nearest `Modal`. Throws an error outside one.

```ts
function useModal(): {
  isOpen: boolean; // whether the modal is open
  isPresent: boolean; // whether the modal is on the page, including while it animates out
  status: "open" | "closing" | "closed";
  openModal: () => void; // opens it
  closeModal: () => void; // closes it
  keepMounted: boolean; // the `keepMounted` prop
};
```
