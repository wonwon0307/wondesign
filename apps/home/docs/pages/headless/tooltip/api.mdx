# API

```ts
import {
  // compound component, with its parts attached
  Tooltip,
  // hook
  useTooltip,
  // named exports
  TooltipProvider,
  TooltipTrigger,
  TooltipContent,
  TooltipArrow,
  // types
  type TooltipProps,
  type TooltipTriggerProps,
  type TooltipContentProps,
  type TooltipArrowProps,
} from "@wondesign/headless/Tooltip";
// or from @wondesign/ui/headless
```

---

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### Provider

`Tooltip` or `TooltipProvider`. Renders no element of its own.

**Props**

- 🔹 **isOpen**, **onOpenChange**: control the open state yourself. See
  [Open State](/headless/tooltip/usage#open-state).
- 🔹 **keepMounted**: closed content is removed from the page by default. This
  hides it with the `hidden` attribute instead. Watch out for
  [closed content that stays visible](/headless/tooltip/overview#watch-out).
- 🔹 **showDelay**, **hideDelay**: how long it waits on hover before showing
  or hiding. Focus and long press ignore them.
- 🔹 **placement**, **forcePlacement**, **align**, **offset**, **padding**:
  the `FloatingOptions` of
  [Floating Position](/interactions/position/floating-position/overview#api).

```ts
interface TooltipProps {
  children: React.ReactNode;
  isOpen?: boolean;
  onOpenChange?: (open: boolean) => void;
  keepMounted?: boolean; // defaults to `false`
  showDelay?: number; // in ms, defaults to `300`
  hideDelay?: number; // in ms, defaults to `0`
  placement?: "top" | "bottom" | "left" | "right"; // defaults to `"bottom"`
  forcePlacement?: boolean; // defaults to `false`
  align?: "start" | "center" | "end"; // defaults to `"center"`
  offset?: number; // in px, defaults to `4`
  padding?: number; // in px, defaults to `8`
}
```

### Trigger

`Tooltip.Trigger` or `TooltipTrigger`. Renders a `<button>` that the tooltip
describes, and accepts all props of [Headless Button](/headless/button/api),
except `type`, `aria-describedby`, `onMouseEnter`, `onMouseLeave`, `onFocus`
and `onBlur`. Use it outside `Tooltip.Content`. Inside it, **it only logs a
warning** in development.

**A click doesn't open the tooltip.** On touch screens, a long press opens it
instead. The hide timer stops while the pointer is on the trigger.

**Props**

- 🔹 **isDisabled**: it can't be pressed, but **still shows its tooltip**, so
  it can explain why it's disabled.

```ts
interface TooltipTriggerProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Content

`Tooltip.Content` or `TooltipContent`. Renders a `<div>`, and accepts all its
props, except `id`, `role`, `hidden`, `onMouseEnter` and `onMouseLeave`.
The hide timer stops while the pointer is on the content, so the tooltip stays
open.

**Props**

- 🔹 **disablePortal**: renders the content where it is, instead of in a
  [Portal](/headless/portal) at the end of `<body>`. Watch out for
  [content that ends up somewhere unexpected](/headless/tooltip/overview#watch-out).

```ts
interface TooltipContentProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  disablePortal?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-placement": "top" | "bottom" | "left" | "right"; // the side it ended up on, after flipping
```

### Arrow

`Tooltip.Arrow` or `TooltipArrow`. Renders a `<div>`, and accepts all its
props, except `aria-hidden`. Must be used inside `Tooltip.Content`.

**Props**

- 🔹 **children**: the arrow's shape, like an SVG.

```ts
interface TooltipArrowProps {
  children?: React.ReactNode;
  // ...
}
```

**Data Attributes**

```ts
"data-placement": "top" | "bottom" | "left" | "right"; // the side the content ended up on, after flipping
```

## Hooks

### useTooltip

Reads the state and position of the nearest `Tooltip`. Throws an error
outside one.

```ts
function useTooltip(): {
  isOpen: boolean; // whether the tooltip is open
  isPresent: boolean; // whether the content is on the page, including while it animates out
  status: "open" | "closing" | "closed";
  showImmediate: () => void; // shows it, without the delay
  showWithDelay: () => void; // shows it after `showDelay`
  hideImmediate: () => void; // hides it, without the delay
  hideWithDelay: () => void; // hides it after `hideDelay`
  keepMounted: boolean; // the `keepMounted` prop
  placement: "top" | "bottom" | "left" | "right"; // the side it ended up on, after flipping
  content: { x: number; y: number }; // from the top left of the viewport
  arrow: { x: number; y: number }; // from the top left of the content
  isPositioned: boolean; // whether the position has been worked out since it opened
  updatePosition: () => void; // works out the position again
};
```
