# API

```ts
import {
  // compound component, with its parts attached
  Popover,
  // hook
  usePopover,
  // named exports
  PopoverProvider,
  PopoverTrigger,
  PopoverContent,
  PopoverTitle,
  PopoverClose,
  PopoverArrow,
  // types
  type PopoverProps,
  type PopoverTriggerProps,
  type PopoverContentProps,
  type PopoverTitleProps,
  type PopoverCloseProps,
  type PopoverArrowProps,
} from "@wondesign/headless/Popover";
// or from @wondesign/ui/headless
```

---

## Components

Each part below lists its key props, followed by its data attributes if it
has any.

### Provider

`Popover` or `PopoverProvider`. Renders no element of its own.

**Props**

- 🔹 **isOpen**, **onOpenChange**: control the open state yourself. See
  [Open State](/headless/popover/usage#open-state).
- 🔹 **defaultOpen**: starts the popover open.
- 🔹 **keepMounted**: closed content is removed from the page by default. This
  hides it with the `hidden` attribute instead, so what's inside keeps its
  state. Watch out for
  [closed content that stays visible](/headless/popover/overview#watch-out).
- 🔹 **placement**, **forcePlacement**, **align**, **offset**, **padding**:
  the `FloatingOptions` of
  [Floating Position](/interactions/position/floating-position/overview#api).
- 🔹 **disableOutsideClick**: keeps the popover open on a click outside the
  content.
- 🔹 **disableEscapeKey**: keeps the popover open on `Esc`.
- 🔹 **initialFocusRef**, **returnFocusRef**: the focus options. See
  [Focus Management](/headless/popover/usage#focus-management).

```ts
interface PopoverProps {
  children: React.ReactNode;
  isOpen?: boolean;
  onOpenChange?: (open: boolean) => void;
  defaultOpen?: boolean; // defaults to `false`
  keepMounted?: boolean; // defaults to `false`
  placement?: "top" | "bottom" | "left" | "right"; // defaults to `"bottom"`
  forcePlacement?: boolean; // defaults to `false`
  align?: "start" | "center" | "end"; // defaults to `"center"`
  offset?: number; // in px, defaults to `4`
  padding?: number; // in px, defaults to `8`
  disableOutsideClick?: boolean; // defaults to `false`
  disableEscapeKey?: boolean; // defaults to `false`
  initialFocusRef?: React.RefObject<HTMLElement | null>;
  returnFocusRef?: React.RefObject<HTMLElement | null>;
}
```

### Trigger

`Popover.Trigger` or `PopoverTrigger`. Renders a `<button>`, and accepts all
props of [Headless Button](/headless/button/api), except `type`,
`aria-haspopup`, `aria-expanded` and `aria-controls`. Use it outside
`Popover.Content`. Inside it, **it only logs a warning** in development.

**Props**

- 🔹 **onClick**: runs before the popover opens or closes. Call
  `event.preventDefault()` to keep it as it is. See
  [Running an Action](/headless/popover/usage#running-an-action).

```ts
interface PopoverTriggerProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Content

`Popover.Content` or `PopoverContent`. Renders a non-modal `<dialog>`, and
accepts all standard HTML attributes, except `id`, `role`, `hidden`,
`tabIndex` and `aria-labelledby`.

It **doesn't accept `<dialog>`-only props**, like `open`, `onClose` or
`onCancel`. Use `isOpen` and `onOpenChange` on `Popover` instead.

**Props**

- 🔹 **disablePortal**: renders the content where it is in the DOM, instead of in a
  [Portal](/headless/portal) at the end of `<body>`. Watch out for
  [content that ends up somewhere unexpected](/headless/popover/overview#watch-out).
- 🔹 **aria-label**: names the popover when it has no `Popover.Title`.

```ts
interface PopoverContentProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  disablePortal?: boolean; // defaults to `false`
  "aria-label"?: string; // defaults to `"Popover Content"`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-placement": "top" | "bottom" | "left" | "right"; // the side it ended up on, after flipping
```

### Title

`Popover.Title` or `PopoverTitle`. Renders an `<h2>` that names the popover,
and accepts all its props, except `id`. Must be used inside `Popover.Content`.

Without a title, the popover is named by the content's `aria-label`, so **a
title or an `aria-label` of your own is strongly recommended**.

**Props**

```ts
interface PopoverTitleProps {
  children: React.ReactNode;
  asChild?: boolean; // defaults to `false`
  // ...
}
```

### Close

`Popover.Close` or `PopoverClose`. Renders a `<button>`, and accepts all props
of [Headless Button](/headless/button/api). Must be used inside
`Popover.Content`.

**Props**

- 🔹 **onClick**: runs before the popover closes. Call
  `event.preventDefault()` to keep it open. See
  [Running an Action](/headless/popover/usage#running-an-action).

```ts
interface PopoverCloseProps {
  children: React.ReactNode;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  asChild?: boolean; // defaults to `false`
  isDisabled?: boolean; // defaults to `false`
  isLoading?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Arrow

`Popover.Arrow` or `PopoverArrow`. Renders a `<div>`, and accepts all its
props, except `aria-hidden`. Must be used inside `Popover.Content`.

**Props**

- 🔹 **children**: the arrow's shape, like an SVG.

```ts
interface PopoverArrowProps {
  children?: React.ReactNode;
  // ...
}
```

**Data Attributes**

```ts
"data-placement": "top" | "bottom" | "left" | "right"; // the side the content ended up on, after flipping
```

## Hooks

### usePopover

Reads the state and position of the nearest `Popover`. Throws an error
outside one.

```ts
function usePopover(): {
  isOpen: boolean; // whether the popover is open
  isPresent: boolean; // whether the content is on the page, including while it animates out
  status: "open" | "closing" | "closed";
  showPopover: () => void; // opens it
  hidePopover: () => void; // closes it
  togglePopover: () => void; // opens or closes it
  keepMounted: boolean; // the `keepMounted` prop
  placement: "top" | "bottom" | "left" | "right"; // the side it ended up on, after flipping
  content: { x: number; y: number }; // from the top left of the viewport
  arrow: { x: number; y: number }; // from the top left of the content
  isPositioned: boolean; // whether the position has been worked out since it opened
  updatePosition: () => void; // works out the position again
};
```
