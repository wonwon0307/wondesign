  `@wondesign/theme` is a small React layer that decides which theme the page

## Key Features

- ✅ **Named Themes**: Pick from a flat list of themes
- ✅ **Light and Dark**: Switch between light, dark and system, with one or more themes for each side
- ✅ **Follows the OS**: Can follow the user's OS light / dark setting, even when it changes
- ✅ **Persistence**: The user's choice is saved and re-applied on every visit
- ✅ **Cross-Tab Sync**: Change the theme in one tab, and every other open tab switches with it
- ✅ **No First-Paint Flash**: Prevents quick flashes on the very first paint
- ✅ **Hydration-Safe**: Works with server rendering, without hydration mismatch errors
- ✅ **Plain CSS Hooks**: Style each theme with plain CSS — no runtime styling needed

## Ways to Theme

There are three ways to theme your app, from the simplest to the most
flexible. Pick one per app.

- ⭐ **[Light-Dark](/foundations/theme/setup#light-dark)** — a light / dark /
  system switch.
- ⭐ **[Advanced Light-Dark](/foundations/theme/setup#advanced-light-dark)** —
  Light-Dark with more than one theme per side.
- ⭐ **[Named Themes](/foundations/theme/setup#named-themes)** — a flat list
  of themes, none tied to light or dark.

---

## How It Works

The provider decides which theme is active, writes it to `<html>`, and saves
the user's choice, which beats your defaults. With Light-Dark, a **mode** of
`"light"`, `"dark"` or `"system"` decides which side's theme is used, and the
color scheme is written too, as the `color-scheme` property that
`light-dark()` colors follow:

```html
<!-- Named Themes -->
<html data-theme="ocean"></html>

<!-- Light-Dark, with "midnight" picked for dark -->
<html
  data-theme="midnight"
  data-color-scheme="dark"
  style="color-scheme: dark"
></html>
```

**Saved choices**:

- 🔹 A saved theme you've since removed falls back to your default.
- 🔹 If the browser can't save the choice, like in some private browsing
  modes, the theme still works until the page is closed.
- 🔹 Apps on the same origin share the saved choice. Give each its own
  `storageKey` if they shouldn't.

## Known Issues

- 🐞 **light-dark() colors in NextJS**: Colors built with `light-dark()` may not follow the theme, or fall back to an unexpected color, when your build tool rewrites `light-dark()` for older browsers. See the [NextJS setup](/foundations/theme/setup#nextjs-app-router) for the fix
