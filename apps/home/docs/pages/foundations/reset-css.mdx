## Installation

```bash
pnpm add @wondesign/reset-css
```

With [All-in-One](/all-in-one), the reset is already part of
`@wondesign/ui/styles.css`, so there's nothing else to install.

---

## Usage

A few common ways to load it — pick whichever fits your setup.

### App root import

Import the CSS from the root of the app. For example, `app/layout.tsx` of NextJS App Router.

```tsx
// layout.tsx
import "@wondesign/reset-css";
// or import "@wondesign/ui/styles.css";

export default function RootLayout() {
  // ...
}
```

### Root CSS import

Import the CSS from the root CSS of the app.
Make sure this import is done as high in the tree as possible, before any other styles.

```css
/* root.css */
@import "@wondesign/reset-css";
/* or @import "@wondesign/ui/styles.css"; */
```

And import the root CSS from app root.

```tsx
// root.tsx
import "./root.css";

export default function RootLayout() {
  // ...
}
```

### Other setups

`@wondesign/reset-css` is just a stylesheet — nothing about it depends on a
specific loading mechanism. Any setup that can load a CSS file works, like a
`<link>` tag or your bundler's global CSS entry.

## What It Changes

Most of the reset only evens out browser differences. A few rules change how
plain elements look:

- 🔸 **Lists**: `ul` and `ol` lose their bullets and indent.
- 🔸 **Links**: `a` takes its parent's color and loses its underline.
- 🔸 **Media**: `img`, `video`, `canvas` and `svg` become `display: block`, so
  an inline icon no longer sits within a line of text.
- 🔸 **Forms**: `button`, `input`, `select` and `textarea` lose their border,
  background and padding.
- 🔸 **Dialogs**: `dialog` loses its margin, so a modal dialog is no longer
  centered.

---

## Compatibility

⚠️ **Tailwind.** Tailwind's Preflight layer already applies its own reset.
Importing both can cause rules to double up or conflict — pick one.

⚠️ **Safari lists.** Without a list style, Safari's VoiceOver stops
announcing `ul` and `ol` as lists. Add `role="list"` to the lists that should
still be announced.
