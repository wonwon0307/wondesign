# Styling

Every token can be used in two ways: as a key on the `tokens` object, or as a
CSS variable. Both resolve to the same value. Use the `tokens` object wherever
you write styles in JavaScript, and the CSS variables wherever you write CSS.

**CSS variables can't be used inside media queries**, so `mediaQueries` holds
plain query strings instead. **They're JavaScript strings, so they only work
where you write styles in JavaScript.**

```ts
import { mediaQueries, tokens } from "@wondesign/tokens";

tokens.spacing.md; // "var(--spacing-md, 8px)"
mediaQueries.breakpoints.small; // "screen and (width < 768px)"
```

---

## Inline Styles

Every token is a plain string, so it works as a value in React's `style` prop:

```tsx
import { colorWithOpacity, tokens } from "@wondesign/tokens";

<div
  style={{
    padding: tokens.spacing.md,
    borderRadius: tokens.radius.md,
    backgroundColor: colorWithOpacity(tokens.colors.primary, 0.1),
    color: tokens.colors.primary,
  }}
/>;
```

**Inline styles can't hold media queries or states like `:hover`.** Use one of
the approaches below for those.

---

## CSS-in-JS

With template-literal libraries like styled-components and Emotion,
interpolate tokens straight into the CSS, and queries after `@media`:

```tsx
import styled from "styled-components"; // or "@emotion/styled"
import { mediaQueries, tokens } from "@wondesign/tokens";

const Card = styled.div`
  padding: ${tokens.spacing.lg};
  border-radius: ${tokens.radius.md};
  background-color: ${tokens.colors.surface};

  @media ${mediaQueries.breakpoints.small} {
    padding: ${tokens.spacing.md};
  }
`;
```

Object-style APIs, such as Emotion's `css` prop, take tokens the same way as
inline styles.

## Vanilla Extract

`vanilla-extract` takes tokens as style values, and queries as keys under
`@media`:

```ts
// card.css.ts
import { style } from "@vanilla-extract/css";
import { mediaQueries, tokens } from "@wondesign/tokens";

export const card = style({
  padding: tokens.spacing.lg,
  borderRadius: tokens.radius.md,
  backgroundColor: tokens.colors.surface,
  "@media": {
    [mediaQueries.breakpoints.small]: {
      padding: tokens.spacing.md,
    },
  },
});
```

`hoverable` keeps hover styles off touch screens, where a tap would otherwise
leave them stuck on, and `reducedMotion` turns off animations for users who've
asked their system for less motion:

```ts
export const link = style({
  transition: "color 200ms ease",
  "@media": {
    [mediaQueries.hoverable]: {
      selectors: { "&:hover": { color: tokens.colors.primary } },
    },
    [mediaQueries.reducedMotion]: {
      transition: "none",
    },
  },
});
```

The same works with any zero-runtime library that takes style objects at
build time.

## Tailwind CSS

Tailwind v4 reads CSS variables in any utility with the `(--variable)` syntax:

```tsx
<div className="rounded-(--radius-md) bg-(--color-surface) p-(--spacing-lg)" />
```

**No Tailwind configuration is needed.** The variables come from the token
stylesheet you installed in [Quick Start](/foundations/tokens/quick-start).

## Plain CSS

In CSS files, including CSS Modules and Sass, use the CSS variables directly,
and write media queries out:

```css
.card {
  padding: var(--spacing-lg);
  border-radius: var(--radius-md);
  background-color: var(--color-surface);
}

@media screen and (width < 768px) {
  .card {
    padding: var(--spacing-md);
  }
}
```

## JavaScript

To react to a query in code, pass it to `matchMedia`:

```ts
import { mediaQueries } from "@wondesign/tokens";

const small = window.matchMedia(mediaQueries.breakpoints.small);

small.matches; // true while the viewport is narrower than 768px
small.addEventListener("change", (event) => {
  console.log(event.matches);
});
```
