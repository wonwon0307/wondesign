# WonDesign Foundations

**WonDesign Foundations** is the **skeleton for design systems** — the
**low-level infrastructure** that components like alerts, popovers and tabs
are built on.

Every app or project ends up redoing the same groundwork — for example, a
color palette, a CSS reset, a set of tokens, or focus and keyboard handling.
Foundations standardize that repetitive work into small, single-purpose
packages, so it's done once and you can spend your time on the business logic
that makes your product work.

---

## Philosophy

> **Opinionated logic, unopinionated style.**

Foundations take a strong stance on **behaviour**, but leave the **look** to
you. The hooks render nothing, and tokens and theme decide how your styles
reach the page, not what they look like. Their default values are there to
start from, not to keep.

This makes Foundations a **safe dependency for any design system**, whatever
its brand or styling approach. Build your own components on top of them, the
same way [Headless Components](/headless) and
[Styled Components](/components) are built.

---

## Packages

**Every package stands on its own** — install only the ones you use. None of
them depends on another. To get them all under one name, install
[All-in-One](/all-in-one), which re-exports every package below.

### Primitives

The base layer every app sits on — styles, values and themes.

- 📦 **[`@wondesign/reset-css`](/foundations/reset-css)** — A single stylesheet
  that smooths out browser defaults, so every browser starts from the same
  baseline.
- 📦 **[`@wondesign/tokens`](/foundations/tokens)** — Semantic design tokens as
  CSS variables and a typed object, with light and dark palettes and media
  queries.
- 📦 **[`@wondesign/theme`](/foundations/theme)** — Light / dark or
  named-theme switching for React, saved, synced across tabs and free of
  first-paint flashes.

### Interactions

React hooks for the behaviour behind interactive components. They hold **no
markup and no styles** — attach them to your own elements.

- 📦 **[`@wondesign/disclosure`](/foundations/disclosure)** — Open / closed state,
  closing animations and scroll locking for anything that shows and hides.
- 📦 **[`@wondesign/focus`](/foundations/focus)** — Arrow key navigation, focus
  on open and close, focus traps and an inert background.
- 📦 **[`@wondesign/key-events`](/foundations/key-events)** — Closing on Escape
  and cross-platform shortkeys like `Mod+K`.
- 📦 **[`@wondesign/pointer`](/foundations/pointer)** — Clicks outside an element
  and long presses, on mouse, touch and pen.
- 📦 **[`@wondesign/position`](/foundations/position)** — Placing floating
  content next to its trigger, keeping it on screen and pointing an arrow back
  at it.
