# Usage

Everything outside the element becomes inert, all the way up to the whole
page, while the element and everything inside it stay usable. The page goes
back to normal when `enabled` turns `false`, or the component unmounts.
Several can be on at once, like an alert opened over a dialog, and the page
behind stays inert until the last one closes, in any order.

- 📌 Elements that were inert before stay inert.

---

## Making the Background Inert

This hook works best together with [Auto Focus](/foundations/focus/auto-focus)
and [Focus Trap](/foundations/focus/focus-trap). **On its own, it doesn't move
focus in or keep Tab inside**. Focus on something that becomes inert is lost,
and Tab moves out to the browser's address bar after the last element.
`useAutoFocus` moves focus into the content, and `useFocusTrap` keeps Tab
cycling inside it:

```tsx
import { useRef, useState } from "react";
import { useAutoFocus } from "@wondesign/focus/auto-focus";
import { useBackgroundInert } from "@wondesign/focus/background-inert";
import { useFocusTrap } from "@wondesign/focus/trap";

export function DeleteDialog() {
  const [isOpen, setIsOpen] = useState(false);
  const dialogRef = useRef<HTMLDivElement>(null);

  useAutoFocus(dialogRef, { enabled: isOpen });
  useFocusTrap(dialogRef, { enabled: isOpen });
  useBackgroundInert(dialogRef, { enabled: isOpen });

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Delete</button>
      {isOpen && (
        <div ref={dialogRef} role="dialog" aria-modal="true" tabIndex={-1}>
          <p>Delete this file?</p>
          <button onClick={() => setIsOpen(false)}>Cancel</button>
          <button>Delete</button>
        </div>
      )}
    </>
  );
}
```

---

## Watch Out

- ⚠️ **Pass the open state to `enabled`**: With `enabled` always `true`, the
  hook turns on before content that's rendered conditionally appears, and
  **the page behind never becomes inert**:

  ```tsx
  // ❌ the hook is already on when the dialog appears, so it never sees it
  useBackgroundInert(dialogRef, { enabled: true });

  // ✅ the hook turns on together with the dialog
  useBackgroundInert(dialogRef, { enabled: isOpen });

  return isOpen ? <div ref={dialogRef}>…</div> : null;
  ```

- ⚠️ **Backdrops and overlays outside the element become inert**: A
  backdrop, overlay or scrim rendered next to the element is outside it, so it
  **can't be clicked**, and closing on a click there won't work. Either keep
  it inside the element, by passing a wrapper's ref, or close with
  [Click Outside](/foundations/pointer/click-outside) instead, which listens
  on the whole page:

  ```tsx
  // ❌ the backdrop is outside the element, so it's inert and can't be clicked
  <>
    <div className="backdrop" onClick={closeDialog} />
    <div ref={dialogRef} role="dialog">…</div>
  </>

  // ✅ the backdrop is inside the element, so it stays clickable
  <div ref={wrapperRef}>
    <div className="backdrop" onClick={closeDialog} />
    <div role="dialog">…</div>
  </div>
  ```
