## Installation

```bash
pnpm add @wondesign/ui
```

<Callout variant="warning" title="Requires React 19.2">
  `@wondesign/ui` needs React 19.2 or later.
</Callout>

---

## Key Features

- ✅ **One Install**: Every package that runs in your app, with a single dependency
- ✅ **One Version**: A single version to update, instead of one per package
- ✅ **Separate Entries**: Import each package from its own entry, so you only bundle what you use

---

## What's Included

- 🔹 **Styling**: every [styling package](/styling)
- 🔹 **Interactions**: every [interaction package](/interactions)
- 🔹 **Headless Components**: every component in
  [`@wondesign/headless`](/headless)
- 🔹 **Styled Components**: every [styled package](/components)

[SVG2TSX](/svg2tsx) isn't included. It's a CLI you run at build
time, so install it on its own, as a dev dependency.

## Setting Up Your App

The setup is the same as in [Getting Started](/getting-started), with every
import from `@wondesign/ui`. For example, in NextJS (App Router):

```tsx
// app/layout.tsx
import "@wondesign/ui/styles.css";
import { wondesignTokenVariables } from "@wondesign/ui/tokens";
import { LightDarkProvider } from "@wondesign/ui/theme";
import { LightDarkScript } from "@wondesign/ui/server";

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <style dangerouslySetInnerHTML={{ __html: wondesignTokenVariables }} />
        <LightDarkScript />
      </head>
      <body>
        <LightDarkProvider>{children}</LightDarkProvider>
      </body>
    </html>
  );
}
```

`@wondesign/ui/styles.css` is the CSS reset. Each component brings its own
styles, so there's nothing else to import.

## Imports

Each package has its own entry, named after it:

```tsx
import { Button } from "@wondesign/ui/buttons";
import { Heading, Paragraph } from "@wondesign/ui/texts";
import { useFocusTrap } from "@wondesign/ui/focus";
```

Headless components come from the entry of their styled package, prefixed with
`Headless`, so they never clash with styled components of the same name:

```tsx
import { Button, HeadlessButton } from "@wondesign/ui/buttons";
import { Anchor, HeadlessAnchor } from "@wondesign/ui/links";
```
