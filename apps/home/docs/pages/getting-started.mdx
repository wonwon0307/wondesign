# Getting Started

Install the packages you need, and they work right away, with no setup
required.

<Callout variant="warning" title="Requires React 19.2">
  WonDesign needs React 19.2 or later.
</Callout>

---

## Choosing What to Install

There are two ways to install WonDesign: everything at once, or only the
packages you need.

### All-in-One

[`@wondesign/ui`](/all-in-one) brings every package that runs in your app
under one name.

### Package by Package

Install only the packages you need, from any part, like `@wondesign/tokens`
from Styling, `@wondesign/focus` from Interactions, `@wondesign/buttons` from
Styled Components, or [`@wondesign/headless`](/headless) alone to build your own
components in your own look. Each package's page shows how to install it.

Packages from different parts mix freely, like a few styled packages
alongside `@wondesign/headless` in the same app.

## Setting Up Your App

Every package works without this setup. It adds a CSS reset, your own token
values, light / dark switching and fonts on top, as described in
[Styling](/styling). For example, in NextJS (App Router):

```tsx
// app/layout.tsx
import "@wondesign/reset-css";
import { wondesignTokenVariables } from "@wondesign/tokens";
import { LightDarkProvider } from "@wondesign/theme/light-dark";
import { LightDarkScript } from "@wondesign/theme/light-dark/server";

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <style dangerouslySetInnerHTML={{ __html: wondesignTokenVariables }} />
        <LightDarkScript />
      </head>
      <body>
        <LightDarkProvider>{children}</LightDarkProvider>
      </body>
    </html>
  );
}
```

NextJS rewrites `light-dark()` for older browsers, so **`light-dark()` colors
may ignore the theme**. See [Known Issues](/styling#known-issues) in Styling
for the fix.

With All-in-One, the same imports come from `@wondesign/ui`. See
[All-in-One](/all-in-one).

For other frameworks, fonts and other ways to theme, see
[Tokens Setup](/styling/tokens/setup) and
[Theme Setup](/styling/theme/setup).
