```bash

```

With [All-in-One](/all-in-one), import from `@wondesign/ui/pointer` instead.

<Callout variant="warning" title="Requires React 19.2">

</Callout>

---

## Key Features

- ✅ **Clicks Outside**: Run a callback when the user clicks or taps outside an element
- ✅ **Long Presses**: Run a callback when the user holds a finger on an element

---

## Hooks

Each hook has its own entry, like `@wondesign/pointer/click-outside`, so you
only bundle the ones you use.

- ⭐ **[Click Outside](/interactions/pointer/click-outside)** — calls a
  callback when the user clicks or taps outside an element, to close a
  popover, menu or tooltip.
- ⭐ **[Long Press](/interactions/pointer/long-press)** — calls a callback when
  the user holds a finger on an element, as a touch stand-in for hover.

---

## Upcoming Features

- 🔜 **Swipe**: Run a callback when the user swipes across an element, such as to close a drawer
- 🔜 **Hover Without Touch**: Run callbacks on hover, ignoring the fake hover a tap triggers on touch screens (tooltips, hover cards, link previews, hover menus)
