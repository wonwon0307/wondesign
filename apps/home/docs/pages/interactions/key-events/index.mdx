  `@wondesign/key-events` handles the keyboard interactions that dialogs, menus
  and command palettes rely on. It takes care of the details that are easy to
  get wrong, like platform differences and typing in inputs.
</PackageInfo>

## Installation

```bash
pnpm add @wondesign/key-events
```

With [All-in-One](/all-in-one), import from `@wondesign/ui/key-events`
instead.

<Callout variant="warning" title="Requires React 19.2">
  `@wondesign/key-events` needs React 19.2 or later.
</Callout>

---

## Key Features

- ✅ **Escape to Close**: Run a callback when the user presses <Keyboard>Esc</Keyboard>
- ✅ **Cross-Platform Shortkeys**: Bind shortkeys like <Keyboard shortkey="Mod+K" />, with <Keyboard>Mod</Keyboard> following the user's platform
- ✅ **Ready to Show**: Show a shortkey's keys the way the user's platform writes them

---

## Hooks

Each hook has its own entry, like `@wondesign/key-events/escape-key`, so you
only bundle the ones you use.

- ⭐ **[Escape Key](/interactions/key-events/escape-key)** — calls a callback
  when the user presses <Keyboard>Esc</Keyboard>, to close a dialog, menu or
  tooltip.
- ⭐ **[Shortkey](/interactions/key-events/shortkey)** — listens for a shortkey
  like <Keyboard shortkey="Mod+K" />, and shows its keys for the user's
  platform.
