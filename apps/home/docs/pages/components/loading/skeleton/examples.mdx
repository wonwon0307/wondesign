# Examples

This page explains what each prop of `Skeleton` does. Each example shows the
rendered result, followed by its code.

---

## Sizes

The `width` and `height` properties set the size, as any CSS length, or a
number in pixels. The default width is `"100%"`, as wide as its container,
and the default height is `"1em"`:

<Preview orientation="vertical">
  <Skeleton />
  <Skeleton width="60%" />
  <Skeleton height={40} />
  <Skeleton width={60} height={80} />
</Preview>

```tsx
<Skeleton />
<Skeleton width="60%" />
<Skeleton height={40} />
<Skeleton width={60} height={80} />
```

---

## Lines

The `lines` property draws a paragraph of lines. Every line is as wide as the
paragraph, except the last, which is `60%`. The default is `1`:

<Preview orientation="vertical">
  <Skeleton lines={3} />
</Preview>

```tsx
<Skeleton lines={3} />
```

With `lines`, `width` sets the width of the whole paragraph, and `height`
sets the height of each line:

<Preview orientation="vertical">
  <Skeleton lines={3} width="50%" height={8} />
</Preview>

```tsx
<Skeleton lines={3} width="50%" height={8} />
```

---

## Circles

Pass `circle` to make a circle, like an avatar. It's always as tall as it is
wide, so set only `width`. The default width of a circle is `40px`:

<Preview>
  <Skeleton circle width={24} />
  <Skeleton circle />
  <Skeleton circle width="4rem" />
</Preview>

```tsx
<Skeleton circle width={24} />
<Skeleton circle />
<Skeleton circle width="4rem" />
```

- 📌 **`circle` is ignored when `lines` is more than `1`**, and the lines are
  drawn as usual.

---

## Animations

The `animation` property sets how the skeleton moves. The options are
`"pulse"`, which fades it in and out, `"wave"`, which sweeps a highlight
across it, and `"none"`, which keeps it still. The default is `"pulse"`:

<Preview orientation="vertical">
  <Skeleton animation="pulse" />
  <Skeleton animation="wave" />
  <Skeleton animation="none" />
</Preview>

```tsx
<Skeleton />
<Skeleton animation="wave" />
<Skeleton animation="none" />
```

- 📌 When the user has asked for reduced motion, the pulse is 2 times slower,
  and the wave turns into that slower pulse.
