# Skeleton

`Skeleton` is a placeholder in the shape of the content that's loading, like
a paragraph, an avatar or an image. Show it in place of the content, and
swap it out once the content arrives.

For an action in progress, like saving a form, use
[Spinner](/components/loading/spinner) instead.

```tsx
import { Skeleton } from "@wondesign/loading/Skeleton";
// or
import { Skeleton } from "@wondesign/ui/loading";
```

---

## Key Features

- ✅ **Any Size**: Match the width and height of the content that's loading
- ✅ **Lines of Text**: A paragraph of lines, ending in a shorter one
- ✅ **Circles**: For avatars and icons
- ✅ **Two Animations**: A pulse or a wave, or no animation at all
- ✅ **Respects Reduced Motion**: Fades gently when the user asks for less motion

---

## Usage

`Skeleton` helps you hold the place of content quickly, using its props. Set
its size with `width` and `height`, draw a paragraph with `lines`, and make
a circle with `circle`. Put skeletons together in the layout of the content
they stand for, like an avatar next to a short bio. For what each prop does,
refer to the [Examples tab](/components/loading/skeleton/examples).

<Preview orientation="vertical">
  <div style={{ display: "flex", gap: "var(--spacing-md)", width: "100%" }}>
    <Skeleton circle />
    <Skeleton lines={3} style={{ flex: 1 }} />
  </div>
</Preview>

```tsx
<Skeleton circle />
<Skeleton lines={3} />
```

For every prop, refer to the [API tab](/components/loading/skeleton/api).

Skeletons are hidden from screen readers, so mark the content that's loading
instead, with `aria-busy`:

```tsx
<section aria-busy={isLoading}>
  {isLoading ? <Skeleton lines={3} /> : <Article article={article} />}
</section>
```

## Upcoming Features

- 🔜 **Fit to Content**: Wrap the real content, and take its size while it loads, with no `width` or `height` to set
- 🔜 **Delays**: Wait before showing, and stay a moment before hiding, so quick loads don't flash a placeholder
- 🔜 **Last Line Width**: Set how wide the last line of a paragraph is
