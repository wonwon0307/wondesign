# Examples

This page explains what each prop of `Spinner` does. Each example shows the
rendered result, followed by its code.

---

## Appearances

The `appearance` property sets the spinner's style. The options are
`"default"`, `"tail"`, `"line"` and `"bubble"`, and the default is
`"default"`:

<Preview>
  <Spinner appearance="default" />
  <Spinner appearance="tail" />
  <Spinner appearance="line" />
  <Spinner appearance="bubble" />
</Preview>

```tsx
<Spinner />
<Spinner appearance="tail" />
<Spinner appearance="line" />
<Spinner appearance="bubble" />
```

---

## Sizes

The `size` property sets the width and height, as any CSS length, or a
number in pixels. The default is `"1.25em"`, so the spinner follows the font
size of the text around it:

<Preview>
  <Spinner />
  <Spinner size={16} />
  <Spinner size="2rem" />
  <Spinner size={48} />
</Preview>

```tsx
<Spinner />
<Spinner size={16} />
<Spinner size="2rem" />
<Spinner size={48} />
```

---

## Speeds

The `speed` property sets how fast it spins. The options are `"slow"`,
`"normal"` and `"fast"`, for a full turn in `1.5s`, `1s` or `0.5s`, and the
default is `"normal"`:

<Preview>
  <Spinner speed="slow" />
  <Spinner speed="normal" />
  <Spinner speed="fast" />
</Preview>

```tsx
<Spinner speed="slow" />
<Spinner />
<Spinner speed="fast" />
```

- 📌 When the user has asked for reduced motion, every speed is 2.5 times
  slower.
- 📌 If you set `animationDuration` in `style`, the spinner spins at that
  speed for every user, **ignoring reduced motion**. Use `speed` instead, or
  handle reduced motion yourself.

---

## Colors

The `color` property sets the color, as any CSS color. The default is
`"currentColor"`, so the spinner takes the color of the text around it:

<Preview>
  <Spinner />
  <Spinner color="var(--color-primary)" />
  <Spinner color="purple" />
</Preview>

```tsx
<Spinner />
<Spinner color="var(--color-primary)" />
<Spinner color="purple" />
```

---

## Label

The spinner is hidden from screen readers by default. To have it announced,
like when there's no loading text next to it, pass `aria-label`:

<Preview>
  <Spinner aria-label="Loading results" />
</Preview>

```tsx
<Spinner aria-label="Loading results" />
```
