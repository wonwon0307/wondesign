# Spinner

`Spinner` is a spinning icon, for an action in progress, like saving a form
or loading a list. It's sized to the text around it, so it fits next to a
label or inside a button.

To hold the place of content until it loads, like a list or a card, use
[Skeleton](/components/loading/skeleton) instead.

```tsx
import { Spinner } from "@wondesign/loading/Spinner";
// or
import { Spinner } from "@wondesign/ui/loading";
```

---

## Key Features

- ✅ **Four Styles**: Pick the spinner that fits your design
- ✅ **Matches Its Text**: Takes the size and color of the text around it
- ✅ **Three Speeds**: Slow, normal and fast
- ✅ **Respects Reduced Motion**: Spins slower when the user asks for less motion

---

## Usage

`Spinner` helps you show an action in progress quickly, using its props. Set
its style with `appearance`, and how fast it spins with `speed`. For what
each prop does, refer to the
[Examples tab](/components/loading/spinner/examples).

<Preview>
  <Spinner />
  <span>{"Saving…"}</span>
</Preview>

```tsx
<Spinner />
```

For every prop, refer to the [API tab](/components/loading/spinner/api).

The spinner is hidden from screen readers by default, so mark the content
that's loading instead. Set `aria-busy` on the content while it loads, or
show loading text next to the spinner, which screen readers read like any
other text:

```tsx
<section aria-busy={isLoading}>
  {isLoading ? <Spinner /> : <Results items={items} />}
</section>
```
