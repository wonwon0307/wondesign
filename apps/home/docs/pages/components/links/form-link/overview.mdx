# FormLink

`FormLink` is a link that looks like a [Button](/components/buttons/button),
for going to another page, like "Sign up" or "Back". It builds on
[Anchor](/components/links/anchor).

To run an action instead, like "Save" or "Delete", use
[Button](/components/buttons/button) from `@wondesign/buttons` instead.

```tsx
import { FormLink } from "@wondesign/links/FormLink";
// or
import { FormLink } from "@wondesign/ui/links";
```

---

## Key Features

- ✅ **Three Variants**: Primary, secondary and destructive, for the kind of destination
- ✅ **Filled or Outlined**: A solid background, or a border for less prominent links
- ✅ **Three Sizes**: Small, medium and large, or as wide as its container
- ✅ **Looks Like a Button**: The same look as `Button`, so links and buttons sit side by side
- ✅ **Disabled State**: Navigation is blocked, and the link stays focusable

---

## Usage

`FormLink` helps you render a link that looks like a form button quickly,
using its props. Pass the label as `children` and the destination as `href`,
and set the look with props like `variant` and `outlined`. Below, clicking a
link takes you to the top of the page. For what each prop does, refer to the
[Examples tab](/components/links/form-link/examples).

<Preview>
  <FormLink href="#">Sign up</FormLink>
  <FormLink variant="secondary" href="#">
    {"Back"}
  </FormLink>
  <FormLink variant="destructive" outlined href="#">
    {"Delete account"}
  </FormLink>
</Preview>

```tsx
<FormLink href="/signup">Sign up</FormLink>
<FormLink variant="secondary" href="/">Back</FormLink>
<FormLink variant="destructive" outlined href="/account/delete">Delete account</FormLink>
```

For every prop and data attribute, refer to the
[API tab](/components/links/form-link/api).
