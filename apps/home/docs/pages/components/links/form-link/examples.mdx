# Examples

This page explains what each prop of `FormLink` does. Each example shows the
rendered result, followed by its code. Clicking a link below takes you to the
top of the page.

---

## Appearance

Pick the colors with `variant`, and choose between a solid background and a
border with `outlined`.

### Variants

The `variant` property sets the colors for the kind of destination. It's
`"primary"` by default:

<Preview>
  <FormLink variant="primary" href="#">
    {"Sign up"}
  </FormLink>
  <FormLink variant="secondary" href="#">
    {"Back"}
  </FormLink>
  <FormLink variant="destructive" href="#">
    {"Delete account"}
  </FormLink>
</Preview>

```tsx
<FormLink variant="primary" href="#">Sign up</FormLink>
<FormLink variant="secondary" href="#">Back</FormLink>
<FormLink variant="destructive" href="#">Delete account</FormLink>
```

### Outlined

Pass `outlined` to swap the solid background for a border, for less
prominent links:

<Preview>
  <FormLink variant="primary" outlined href="#">
    {"Log in"}
  </FormLink>
  <FormLink variant="secondary" outlined href="#">
    {"Cancel"}
  </FormLink>
  <FormLink variant="destructive" outlined href="#">
    {"Leave team"}
  </FormLink>
</Preview>

```tsx
<FormLink variant="primary" outlined href="#">Log in</FormLink>
<FormLink variant="secondary" outlined href="#">Cancel</FormLink>
<FormLink variant="destructive" outlined href="#">Leave team</FormLink>
```

## Sizes

The `size` property sets the font size and the padding. It's `"medium"` by
default:

<Preview>
  <FormLink size="small" href="#">
    {"Get started"}
  </FormLink>
  <FormLink size="medium" href="#">
    {"Get started"}
  </FormLink>
  <FormLink size="large" href="#">
    {"Get started"}
  </FormLink>
</Preview>

```tsx
<FormLink size="small" href="#">Get started</FormLink>
<FormLink size="medium" href="#">Get started</FormLink>
<FormLink size="large" href="#">Get started</FormLink>
```

### Stretch

Pass `stretch` to make the link as wide as its container (`100%`), like the
links at the bottom of a form. Links in the same row share the width, and
they line up with a stretched [Button](/components/buttons/button):

<Preview>
  <FormLink stretch variant="secondary" outlined href="#">
    {"Back"}
  </FormLink>
  <FormLink stretch href="#">
    {"Next"}
  </FormLink>
</Preview>

```tsx
<div style={{ display: "flex", gap: "var(--spacing-md)" }}>
  <FormLink stretch variant="secondary" outlined href="#">
    Back
  </FormLink>
  <FormLink stretch href="#">
    Next
  </FormLink>
</div>
```

---

## Content

`children` also accepts your own elements alongside the label, like an icon
on either side. They sit in a row, with space between them:

<Preview>
  <FormLink variant="secondary" outlined href="#">
    <AppIcon icon="download" />
    {"Download guide"}
  </FormLink>
  <FormLink href="#">
    {"Next"}
    <AppIcon icon="chevron-right" />
  </FormLink>
</Preview>

```tsx
import { AppIcon } from "@wondesign/icons";

<FormLink variant="secondary" outlined href="#">
  <AppIcon icon="download" />
  Download guide
</FormLink>
<FormLink href="#">
  Next
  <AppIcon icon="chevron-right" />
</FormLink>
```

---

## Disabled

Pass `isDisabled` to turn the link off. Navigation is blocked, and the link
fades:

<Preview>
  <FormLink href="#">Continue</FormLink>
  <FormLink isDisabled href="#">
    {"Continue"}
  </FormLink>
</Preview>

```tsx
<FormLink href="#">Continue</FormLink>
<FormLink isDisabled href="#">Continue</FormLink>
```
