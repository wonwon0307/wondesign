# Hyperlink

`Hyperlink` is a text link, for links within a sentence or a list. It builds
on [Anchor](/components/links/anchor).

For an action that stays on the page, like "Undo", use
[LinkButton](/components/buttons/link-button) from `@wondesign/buttons`
instead.

```tsx
import { Hyperlink } from "@wondesign/links/Hyperlink";
// or
import { Hyperlink } from "@wondesign/ui/links";
```

---

## Key Features

- ✅ **Fits Its Sentence**: Takes the font size and family of the text around it
- ✅ **Four Appearances**: For the classic link color, primary text, muted text and colored backgrounds
- ✅ **Underline Control**: Underlined on hover, always or never
- ✅ **External Links Handled**: Links to other sites open in a new tab, safely
- ✅ **Router Friendly**: Render your router's link component, with all the same behaviour

---

## Usage

`Hyperlink` helps you add a link within your text. Pass the label as
`children` and the destination as `href`, and place it inside your text. It
takes the font of the text around it, and you can set its look with props
like `appearance` and `underline`. Below, clicking the link takes you to the
top of the page. For what each prop does, refer to the
[Examples tab](/components/links/hyperlink/examples).

<Preview orientation="vertical">
  <p>
    {"Read the "}
    <Hyperlink href="#">{"links overview"}</Hyperlink>
    {" before you start."}
  </p>
</Preview>

```tsx
<p>
  Read the <Hyperlink href="#">links overview</Hyperlink> before you start.
</p>
```

For every prop and data attribute, refer to the
[API tab](/components/links/hyperlink/api).
