# Anchor

`Anchor` makes anything inside it a link, like a card or an image, by
wrapping it in an `<a>`. It builds on [Headless Anchor](/headless/anchor).

Use it to make anything a link when none of
[Hyperlink](/components/links/hyperlink),
[IconLink](/components/links/icon-link) and
[FormLink](/components/links/form-link) fits. It adds only a focus outline
and a disabled cursor, so your content looks the same.

```tsx
import { Anchor } from "@wondesign/links/Anchor";
// or
import { Anchor } from "@wondesign/ui/links";
```

---

## Key Features

- ✅ **No Default Look**: Your content looks the same, with only a focus outline added
- ✅ **External Links Handled**: Links to other sites open in a new tab, safely
- ✅ **Router Friendly**: Render your router's link component, with all the same behaviour
- ✅ **Disabled State**: Navigation is blocked, and the link stays focusable
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`Anchor` helps you turn your own content into a link, without changing how
it looks. Wrap the content in it, and pass `href`. Below, clicking the second
badge takes you to the top of the page. For what each prop does, refer to the
[Examples tab](/components/links/anchor/examples).

<Preview>
  <Badge label="Static" />
  <Anchor href="#">
    <Badge label="Link" />
  </Anchor>
</Preview>

```tsx
// without Anchor
<Badge label="Static" />

// with Anchor
<Anchor href="#">
  <Badge label="Link" />
</Anchor>
```

For every prop and data attribute, refer to the
[API tab](/components/links/anchor/api).

---

## Watch Out

- ⚠️ **Rounded content**: The focus outline follows the corners of the
  `Anchor`, not of your content, so **it has square corners around rounded
  content**. Set a matching `border-radius` on the `Anchor`.
