# Examples

This page explains what each prop of `Anchor` does. Each example shows the
rendered result, followed by its code. Unless stated otherwise, clicking a
link below takes you to the top of the page.

---

## External and Router Links

`Anchor` opens links to other sites in a new tab, and renders your router's
link component with `as`, the same way as the headless `Anchor`. Pass
`openInNewTab` to open your own pages in a new tab too. Below, clicking the
badge opens this page in a new tab:

<Preview>
  <Anchor href="/components/links/anchor/examples" openInNewTab>
    <Badge label="Examples" />
  </Anchor>
</Preview>

```tsx
import Link from "next/link";

<Anchor as={Link} href="/components/links/anchor/examples" openInNewTab>
  <Badge label="Examples" />
</Anchor>;
```

For more, refer to [New Tab](/headless/anchor/usage#new-tab) and
[Router Links](/headless/anchor/usage#router-links).

---

## Disabled

Pass `isDisabled` to turn the link off. Navigation is blocked, and the cursor
turns into a not-allowed cursor:

<Preview>
  <Anchor href="#">
    <Badge label="Available" />
  </Anchor>
  <Anchor href="#" isDisabled>
    <Badge label="Disabled" />
  </Anchor>
</Preview>

```tsx
<Anchor href="#">
  <Badge label="Available" />
</Anchor>

<Anchor href="#" isDisabled>
  <Badge label="Disabled" />
</Anchor>
```

- 📌 **The content doesn't look disabled.** Style it yourself with
  `[data-disabled]`.
