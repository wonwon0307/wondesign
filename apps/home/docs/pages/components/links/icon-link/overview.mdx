# IconLink

`IconLink` is a compact link with a single icon, like a link to GitHub or a
download. It builds on [Anchor](/components/links/anchor).

For an action that stays on the page, like copying, use
[IconButton](/components/buttons/icon-button) from `@wondesign/buttons`
instead.

```tsx
import { IconLink } from "@wondesign/links/IconLink";
// or
import { IconLink } from "@wondesign/ui/links";
```

---

## Key Features

- ✅ **Built-in Icons**: Pass an icon name, and the icon is rendered for you
- ✅ **Your Own Content**: Or pass any content, like a logo
- ✅ **Three Appearances**: Filled, outlined or ghost, for how much the link stands out
- ✅ **Any Size**: Follows the text around it, or takes the size you set
- ✅ **Rounded or Spacious**: Make the link a circle, or give the icon more room

---

## Usage

`IconLink` helps you render an icon-only link quickly, using its props. Pass
an icon name from [`@wondesign/icons`](/components/icons/app-icon/overview#icon-list)
as `icon` and the destination as `href`, and set the look with props like `appearance`
and `rounded`. `children` also accepts your own content in place of `icon`, like
a logo. Below, clicking a link takes you to the top of the page. For what
each prop does, refer to the
[Examples tab](/components/links/icon-link/examples).

<Preview>
  <IconLink icon="download" href="#" aria-label="Download" />
  <IconLink
    icon="package"
    appearance="filled"
    rounded
    href="#"
    aria-label="Packages"
  />
  <IconLink icon="info" appearance="ghost" href="#" aria-label="Help" />
</Preview>

```tsx
<IconLink icon="download" href="#" aria-label="Download" />
<IconLink icon="package" appearance="filled" rounded href="#" aria-label="Packages" />
<IconLink icon="info" appearance="ghost" href="#" aria-label="Help" />
```

- 📌 Give every icon link an `aria-label` that says where it goes, like
  "Help". Without one, **the link has no name**, and screen readers may read
  out its URL instead.

For every prop and data attribute, refer to the
[API tab](/components/links/icon-link/api).
