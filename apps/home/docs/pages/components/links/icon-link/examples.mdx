# Examples

This page explains what each prop of `IconLink` does. Each example shows the
rendered result, followed by its code. Clicking a link below takes you to the
top of the page. The examples below, except the ones under Sizes, use a size
of `20` instead of the default `"1em"`.

---

## Content

Pass an `icon` name from [`@wondesign/icons`](/components/icons/app-icon/overview#icon-list),
or your own content as `children`, like a logo. Passing both is a type
error:

<Preview>
  <IconLink icon="download" size={20} href="#" aria-label="Download" />
  <IconLink href="#" aria-label="GitHub">
    <GithubLogo size={20} />
  </IconLink>
</Preview>

```tsx
<IconLink icon="download" href="#" aria-label="Download" />

<IconLink href="#" aria-label="GitHub">
  <GithubLogo />
</IconLink>
```

- 📌 **`size` is ignored with `children`.** Size your own content yourself.

---

## Appearance

The `appearance` property sets how much the link stands out, from a solid
background to none until hovered. `"outlined"` is the default:

<Preview>
  <IconLink
    icon="download"
    size={20}
    appearance="filled"
    href="#"
    aria-label="Download"
  />
  <IconLink
    icon="download"
    size={20}
    appearance="outlined"
    href="#"
    aria-label="Download"
  />
  <IconLink
    icon="download"
    size={20}
    appearance="ghost"
    href="#"
    aria-label="Download"
  />
</Preview>

```tsx
<IconLink icon="download" appearance="filled" href="#" aria-label="Download" />
<IconLink icon="download" appearance="outlined" href="#" aria-label="Download" />
<IconLink icon="download" appearance="ghost" href="#" aria-label="Download" />
```

### Rounded

Pass `rounded` to make the link a circle:

<Preview>
  <IconLink icon="package" size={20} href="#" aria-label="Packages" />
  <IconLink icon="package" size={20} rounded href="#" aria-label="Packages" />
</Preview>

```tsx
<IconLink icon="package" href="#" aria-label="Packages" />
<IconLink icon="package" rounded href="#" aria-label="Packages" />
```

---

## Sizes

The `size` property sets the size of the icon, as any CSS length, or a
number in pixels. `"1em"` is the default, so the icon follows the font size
around it:

<Preview>
  <IconLink icon="info" href="#" aria-label="Help" />
  <IconLink icon="info" size={24} href="#" aria-label="Help" />
  <IconLink icon="info" size="2rem" href="#" aria-label="Help" />
</Preview>

```tsx
<IconLink icon="info" href="#" aria-label="Help" />
<IconLink icon="info" size={24} href="#" aria-label="Help" />
<IconLink icon="info" size="2rem" href="#" aria-label="Help" />
```

### Spacious

Pass `spacious` to give the icon more room, for a larger click target. It
works well with larger icons, which look cramped in the default padding:

<Preview>
  <IconLink icon="palette" size={20} href="#" aria-label="Themes" />
  <IconLink icon="palette" size={20} spacious href="#" aria-label="Themes" />
  <IconLink icon="palette" size="2rem" href="#" aria-label="Themes" />
  <IconLink
    icon="palette"
    size="2rem"
    spacious
    href="#"
    aria-label="Themes"
  />
</Preview>

```tsx
<IconLink icon="palette" href="#" aria-label="Themes" />
<IconLink icon="palette" spacious href="#" aria-label="Themes" />
<IconLink icon="palette" size="2rem" href="#" aria-label="Themes" />
<IconLink icon="palette" size="2rem" spacious href="#" aria-label="Themes" />
```

---

## Disabled

Pass `isDisabled` to turn the link off. Navigation is blocked, and the link
fades:

<Preview>
  <IconLink icon="download" size={20} href="#" aria-label="Download" />
  <IconLink
    icon="download"
    size={20}
    isDisabled
    href="#"
    aria-label="Download"
  />
</Preview>

```tsx
<IconLink icon="download" href="#" aria-label="Download" />
<IconLink icon="download" isDisabled href="#" aria-label="Download" />
```
