# Styled Components

Styled Components are React components with the WonDesign look, built on
[Headless Components](/headless) and [`@wondesign/tokens`](/styling/tokens).
Each package installs and works on its own.

---

## Two Forms

Many styled packages come in two forms, and some offer both:

- 🎁 **Ready-made**: The parts already put together. Drop them in for simple,
  quick uses.
- 🧩 **Parts**: The pieces of a component, like a tab list, a tab and a tab
  panel, each with the WonDesign look. Arrange them into a component of your
  own.

---

## Styling the Components

Styled components ship as plain, ready-built CSS, so they don't tie you to a
CSS library. Style them with whatever you already use, like Tailwind, CSS
Modules or plain CSS, for your whole app or for one component at a time.

### App-Wide

Every styled component is styled with
[`@wondesign/tokens`](/styling/tokens), as CSS variables. Redeclare a token to
change every component that uses it. Below, every component that uses the
primary color, like a button, turns purple, and every component with medium
corners gets rounder:

```css
:root {
  --color-primary: #7c3aed;
  --radius-md: 12px;
}
```

For a full set of values, dark mode and scoped themes, refer to
[Customization](/styling/tokens/setup#customization).

### One Component

To change a single use, like adding space above one button, pass `className`
or `style` as you would on any element. Your class is added to the
component's own, so its default look stays, and your styles apply on top:

```tsx
<Button className="checkout">Checkout</Button>
```

```css
.checkout {
  margin-top: var(--spacing-lg);
}
```

Use token values over hard-coded ones, like `var(--spacing-lg)` above, so your
styles stay consistent with the rest of the app.

## Packages

Packages are grouped by what they're for. Atoms are the small building
blocks. Content Display shows content on the page. Feedback tells the user
what's happening.

### Atoms

- 📦 **[`@wondesign/icons`](/components/icons)** — The WonDesign icon set,
  rendered by name with one type-safe component.
- 📦 **[`@wondesign/buttons`](/components/buttons)** — A plain clickable base,
  form buttons, icon buttons, and buttons that look like links.
- 📦 **[`@wondesign/links`](/components/links)** — A plain link base, text
  links, icon links, and links that look like buttons.

### Content Display

- 📦 **[`@wondesign/texts`](/components/texts)** — Headings, paragraphs,
  descriptions, callouts and badges.
- 📦 **[`@wondesign/code`](/components/code)** — Inline code, code blocks with
  a copy button, and keyboard keys for showing shortkeys.
- 📦 **[`@wondesign/separators`](/components/separators)** — Decorative
  dividers with an optional label, and theme breaks for a real change of topic.

### Feedback

- 📦 **[`@wondesign/alert`](/components/alert)** — Alerts and confirms, shown
  with a single function call from anywhere in your app.
- 📦 **[`@wondesign/toast`](/components/toast)** — Short messages that close on
  their own, shown with a single function call.
- 📦 **[`@wondesign/loading`](/components/loading)** — Spinners and skeletons
  for content that's still on its way.
