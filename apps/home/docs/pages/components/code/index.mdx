---

## Key Features

- ✅ **Semantic Markup**: Inline code, code blocks and keys, each rendering the right native element
- ✅ **Platform-Aware Shortcuts**: Keyboard shortcuts are shown the way the user's platform writes them
- ✅ **Syntax Highlighting**: Code is highlighted in the page's light or dark color scheme
- ✅ **Consistent Code**: Code looks the same across your app, in the same code font
- ✅ **Styleable**: Your `className` and `style` are applied on top of the defaults

---

## Components

The components cover code and keys, both within a sentence and on their own.
Use them anywhere your app shows code, like in docs and tutorials, or
explains how to use your app from the keyboard.

- ⭐ **[InlineCode](/components/code/inline-code)** — a short piece of code
  within a sentence.
- ⭐ **[CodeBlock](/components/code/code-block)** — a framed block of
  syntax-highlighted code, with a matching copy button.
- ⭐ **[Keyboard](/components/code/keyboard)** — a key, like `Enter`, or a
  shortcut, shown the way the user's platform writes it.
