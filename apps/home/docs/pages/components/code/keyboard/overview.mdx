# Keyboard

`Keyboard` is a key, like `Enter`, or a keyboard shortcut, like `Mod+K`. A
shortcut is shown the way the user's platform writes it: `⌘ K` on a Mac, and
`Ctrl K` on Windows. It renders the keys in `<kbd>` elements, the native
markup for keyboard input.

Shortcuts are written as shortkeys, the same way as for
[Shortkey](/interactions/key-events/shortkey) in `@wondesign/key-events`, so
you can show the same shortkey you bind.

```tsx
import { Keyboard } from "@wondesign/code/Keyboard";
// or
import { Keyboard } from "@wondesign/ui/code";
```

---

## Key Features

- ✅ **Your Own Keys**: Shows any key exactly as you write it, like `Enter` or `⌘`
- ✅ **Shortkeys**: Shows a shortcut from the same shortkey you bind with `useShortkey`
- ✅ **Platform-Aware**: Shows `⌘ K` on a Mac, and `Ctrl K` everywhere else
- ✅ **Familiar Order**: Shows modifiers in each platform's usual order
- ✅ **Screen Reader Support**: Reads a shortcut's key names, handled for you
- ✅ **Three Sizes**: Small, medium and large, to match the text around it

---

## Usage

`Keyboard` helps you show keys quickly, using its props. Pass a key as
`children`, or a shortcut as `shortkey`, and set its size with `size`. For
what each prop does, refer to the
[Examples tab](/components/code/keyboard/examples).

<Preview orientation="vertical">
  <p>
    {"Press "}
    <Keyboard>{"Enter"}</Keyboard>
    {" to send the message, or "}
    <Keyboard shortkey="Mod+K" />
    {" to search."}
  </p>
</Preview>

```tsx
<Keyboard>Enter</Keyboard>
<Keyboard shortkey="Mod+K" />
```

For every prop, refer to the [API tab](/components/code/keyboard/api).

- 📌 Pass either `children` or `shortkey`. Passing both is a type error.
- 📌 `children` are **shown exactly as you pass them**, with no platform
  detection, so `⌘` stays `⌘` on Windows too.
- 📌 **A `Keyboard` with a `shortkey` with modifiers renders nothing on the
  server**, and
  appears after hydration in the browser. The text around it may shift when
  it does.

When you bind a shortkey with `useShortkey`, show it with `Keyboard` on the
button that does the same thing, so users can learn the shortcut. Keep the
shortkey in one constant, so the shortcut you show is always the one that
works:

```tsx
const SEARCH_SHORTKEY = "Mod+K";

useShortkey(SEARCH_SHORTKEY, openSearch);

<button onClick={openSearch}>
  Search <Keyboard shortkey={SEARCH_SHORTKEY} />
</button>;
```

## Styling

`Keyboard` relies on the WonDesign tokens, especially the code font. To
change the look of every key across your app, redeclare those tokens. For
their names, refer to
[Design Tokens](/styling/tokens/design-tokens#font-family). To change a
single key's look beyond its props, pass `className` or `style`.

---

## Known Issues

- 🐞 **Some screen readers skip shortcuts with modifiers**: Not every screen
  reader reads a shortcut's label, so some **read nothing** for it.
