# Examples

This page explains what each prop of `Keyboard` does. Each example shows the
rendered result, followed by its code.

---

## Keys

Pass a shortcut as `shortkey`, or your own key as `children`. Passing both is
a type error.

### Shortkeys

Pass a shortcut as `shortkey`. For how to write one, refer to
[Writing Shortkeys](/interactions/key-events/shortkey/usage#writing-shortkeys).
`Keyboard` shows it through
[useShortkeyDisplay](/interactions/key-events/shortkey/usage#showing-a-shortkey),
with the keys and the modifier order of the user's platform:

<Preview orientation="vertical">
  <Keyboard shortkey="Mod+Shift+P" />
</Preview>

```tsx
<Keyboard shortkey="Mod+Shift+P" />
```

### Your Own Keys

Pass a key as `children`. It's shown exactly as you pass it, and can be any
content, from a symbol like `⌘` to an icon:

<Preview orientation="vertical">
  <p>
    {"Press "}
    <Keyboard aria-label="Enter">
      <AppIcon icon="enter-key" />
    </Keyboard>
    {" to send, or "}
    <Keyboard>{"⌘"}</Keyboard>
    {" to see more options."}
  </p>
</Preview>

```tsx
<Keyboard aria-label="Enter">
  <AppIcon icon="enter-key" />
</Keyboard>
<Keyboard>⌘</Keyboard>
```

- 📌 Content with no text, like an icon, **has nothing for screen readers to
  read**, so pass an `aria-label` with it.

---

## Sizes

The `size` property sets the font size and the padding of every key. The
options are `"small"`, `"medium"` and `"large"`, and the default is
`"small"`, so a key doesn't stand out more than the sentence it's in:

<Preview orientation="vertical">
  <p>
    {"Press "}
    <Keyboard shortkey="Mod+Shift+P" />
    {" to open the command palette."}
  </p>
  <p>
    {"Press "}
    <Keyboard shortkey="Mod+Shift+P" size="medium" />
    {" to open the command palette."}
  </p>
  <p>
    {"Press "}
    <Keyboard shortkey="Mod+Shift+P" size="large" />
    {" to open the command palette."}
  </p>
</Preview>

```tsx
<Keyboard shortkey="Mod+Shift+P" />
<Keyboard shortkey="Mod+Shift+P" size="medium" />
<Keyboard shortkey="Mod+Shift+P" size="large" />
```

---

## Label

By default, screen readers read a shortkey's key names, like "Command Shift
P". To read something else, like what the shortcut does, pass `aria-label`:

<Preview orientation="vertical">
  <Keyboard shortkey="Mod+Shift+P" aria-label="Open the command palette" />
</Preview>

```tsx
<Keyboard shortkey="Mod+Shift+P" aria-label="Open the command palette" />
```
