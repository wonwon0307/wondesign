# Examples

This page explains what each prop of `InlineCode` does. Each example shows the
rendered result, followed by its code.

---

## Sizes

The `size` property sets the font size and the padding together. The options
are `"small"`, `"medium"` and `"large"`, and the default is `"medium"`. Match
the size to the text around it, like `"small"` in a table cell or a caption:

<Preview orientation="vertical">
  <p>
    {"Pass "}
    <InlineCode size="small">{"size"}</InlineCode>
    {" to change the size."}
  </p>
  <p>
    {"Pass "}
    <InlineCode>{"size"}</InlineCode>
    {" to change the size."}
  </p>
  <p>
    {"Pass "}
    <InlineCode size="large">{"size"}</InlineCode>
    {" to change the size."}
  </p>
</Preview>

```tsx
<InlineCode size="small">size</InlineCode>
<InlineCode>size</InlineCode>
<InlineCode size="large">size</InlineCode>
```
