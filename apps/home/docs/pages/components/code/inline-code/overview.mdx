# InlineCode

`InlineCode` is a short piece of code within a sentence, like a prop name, a
file path or a command. It renders the code in a `<code>` element, the
native markup for inline code.

For longer code, on lines of its own, use
[CodeBlock](/components/code/code-block) instead.

```tsx
import { InlineCode } from "@wondesign/code/InlineCode";
// or
import { InlineCode } from "@wondesign/ui/code";
```

---

## Key Features

- ✅ **Three Sizes**: Small, medium and large, to match the text around it
- ✅ **Fits the Text**: Takes the color of the text around it
- ✅ **Wraps Long Code**: Long paths and URLs wrap, instead of running past the edge
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`InlineCode` helps you mark code in a sentence quickly, using its props. Pass
the code as `children`, and set its size with `size`. For what each prop
does, refer to the [Examples tab](/components/code/inline-code/examples).

<Preview orientation="vertical">
  <p>
    {"Run "}
    <InlineCode>{"pnpm add @wondesign/code"}</InlineCode>
    {" to install the package."}
  </p>
</Preview>

```tsx
<InlineCode>pnpm add @wondesign/code</InlineCode>
```

For every prop, refer to the [API tab](/components/code/inline-code/api).

- ⚠️ **Keep inline code short.** Long code, like a file path or a URL, wraps
  as one block inside its own background, **instead of flowing with the
  sentence**.

---

## Styling

`InlineCode` relies on the WonDesign tokens, especially the code font. To
change the look of every inline code across your app, redeclare those
tokens. For their names, refer to
[Design Tokens](/styling/tokens/design-tokens#font-family). To change a
single inline code's look beyond its props, pass `className` or `style`.
