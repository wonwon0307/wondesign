import { CodeBlock, CopyCodeButton } from "@wondesign/ui/code";
import { Preview } from "@/widgets/preview";

# Examples

This page explains what each prop of `CodeBlock` and `CopyCodeButton` does.
Each example shows the rendered result, followed by its code.

---

## Languages

The `lang` property sets the language to highlight the code as. It takes a
language's name, like `"typescript"`, or a common alias, like `"ts"`. The
default is `"plaintext"`, which shows the code with no highlighting. For the
supported languages, refer to Shiki's
[web bundle](https://shiki.style/guide/bundles#shiki-bundle-web):

<Preview orientation="vertical">
  <CodeBlock
    lang="css"
    code={`.card {
    padding: 16px;
    border-radius: 8px;
}`}
  />
  <CodeBlock lang="bash" code="pnpm add @wondesign/code" />
</Preview>

```tsx
<CodeBlock code={css} lang="css" />
<CodeBlock code="pnpm add @wondesign/code" lang="bash" />
```

- 📌 **An unsupported language shows plain text without a warning**. Check
  the spelling when a block isn't highlighted.
- 📌 If highlighting fails, the code is still shown as plain text, with an
  error in the console.
- 📌 Long lines aren't wrapped. They stay on one line, and the block scrolls
  sideways.

---

## Sizes

The `size` property sets the font size of the code. The options are
`"small"`, `"medium"` and `"large"`, and the default is `"medium"`:

<Preview orientation="vertical">
  <CodeBlock size="large" lang="ts" code={`const size = "large";`} />
  <CodeBlock size="medium" lang="ts" code={`const size = "medium";`} />
  <CodeBlock size="small" lang="ts" code={`const size = "small";`} />
</Preview>

```tsx
<CodeBlock code={code} lang="ts" size="large" />
<CodeBlock code={code} lang="ts" />
<CodeBlock code={code} lang="ts" size="small" />
```

---

## Max Lines

Pass `maxNumLines` to show a set number of lines, and scroll for the rest.
The default is `0`, which shows every line:

<Preview orientation="vertical">
  <CodeBlock
    lang="ts"
    maxNumLines={4}
    code={`const colors = {
    primary: "blue",
    secondary: "purple",
    success: "green",
    warning: "orange",
    error: "red",
    text: "black",
    background: "white",
  };`}
  />
</Preview>

```tsx
<CodeBlock code={code} lang="ts" maxNumLines={4} />
```

- 📌 When `maxNumLines` is set, **a `maxHeight` in `style` is replaced** by
  the height of that many lines. Set one or the other, not both.

---

## Line Numbers

Pass `showLineNumbers` to number each line. The numbers can't be selected,
so copying the code leaves them out:

<Preview orientation="vertical">
  <CodeBlock
    lang="ts"
    showLineNumbers
    code={`const a = 1;
const b = 2;
const sum = a + b;`}
  />
</Preview>

```tsx
<CodeBlock code={code} lang="ts" showLineNumbers />
```

---

## Copy Button

`CopyCodeButton` copies its `code` to the clipboard. By default, it shows a
copy icon, which turns into a check once the code is copied. Screen readers
read it as "Copy code", or "Copied" after copying.

**It doesn't position itself**, so place it yourself. It accepts all props of
[Pressable](/components/buttons/pressable), so your `className` and `style`
are applied, including the positioning:

<Preview orientation="vertical">
  <div style={{ position: "relative", alignSelf: "stretch" }}>
    <CodeBlock lang="bash" code="pnpm add @wondesign/code" />
    <CopyCodeButton
      code="pnpm add @wondesign/code"
      style={{
        position: "absolute",
        top: "var(--spacing-md)",
        right: "var(--spacing-md)",
      }}
    />
  </div>
</Preview>

```tsx
<div style={{ position: "relative" }}>
  <CodeBlock code={code} lang="bash" />
  <CopyCodeButton
    code={code}
    style={{ position: "absolute", top: 8, right: 8 }}
  />
</div>
```

### Custom Content

Pass `children` to show your own content instead of the icon, like a text
label. To style the copied state, use `[data-state="copied"]`, which is
`"idle"` otherwise:

<Preview orientation="vertical">
  <CopyCodeButton code="pnpm add @wondesign/code">{"Copy"}</CopyCodeButton>
</Preview>

```tsx
<CopyCodeButton code={code}>Copy</CopyCodeButton>
```

- 📌 Screen readers still read the button as "Copy code" or "Copied",
  **instead of your content**.

### Other Props

To respond to the copy, pass `onCopy` and `onCopyFail`. `onCopy` runs after
the code is copied, and `onCopyFail` runs when copying fails, like when the
browser blocks the clipboard.

Also, set how long the button stays in its copied state with `timeout`,
in milliseconds. The button is disabled until then, and the default is `2000`:

```tsx
<CopyCodeButton
  code={code}
  // `toast` from @wondesign/toast
  onCopy={() => toast.success("Copied!")}
  onCopyFail={() => toast.error("Couldn't copy the code")}
  timeout={3000}
/>
```

- 📌 **Without `onCopyFail`, a failed copy shows nothing to the user**, and
  is only logged in the console.
