# CodeBlock

`CodeBlock` is a framed block of syntax-highlighted code, with optional line
numbers. It renders the code in a `<code>` element inside a `<pre>`, the
native markup for a block of code. The module also exports
`CopyCodeButton`. Wire the two together to let users copy the code in one
click.

```tsx
import { CodeBlock, CopyCodeButton } from "@wondesign/code/CodeBlock";
// or
import { CodeBlock, CopyCodeButton } from "@wondesign/ui/code";
```

---

## Key Features

- ✅ **Syntax Highlighting**: Powered by [Shiki](https://shiki.style), in the page's light or dark color scheme
- ✅ **Three Sizes**: Small, medium and large, to fit the content around it
- ✅ **Max Lines**: Show a set number of lines, and scroll for the rest
- ✅ **Line Numbers**: Number each line, without the numbers ending up in copied code
- ✅ **Copy Button**: Copies the code in one click, and shows a check once it's copied
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`CodeBlock` helps you show highlighted code quickly, using its props. Pass
the code as `code` and its language as `lang`, and set it up with props like
`size` and `maxNumLines`. To add a copy button, place a `CopyCodeButton`
with the same `code` next to it. For what each prop does, refer to the
[Examples tab](/components/code/code-block/examples).

<Preview orientation="vertical">
  <div style={{ position: "relative", alignSelf: "stretch" }}>
    <CodeBlock
      lang="ts"
      code={`function add(a: number, b: number) {
    return a + b;
}`}
    />
    <CopyCodeButton
      code={`function add(a: number, b: number) {
    return a + b;
}`}
      style={{
        position: "absolute",
        top: "var(--spacing-md)",
        right: "var(--spacing-md)",
      }}
    />
  </div>
</Preview>

```tsx
const code = `function add(a: number, b: number) {
  return a + b;
}`;

<div className="wrapper">
  <CodeBlock code={code} lang="ts" />
  <CopyCodeButton code={code} className="copy" />
</div>;
```

For every prop, refer to the [API tab](/components/code/code-block/api).

- 📌 Pass the code as `code`, since **`children` are ignored**.

---

## Styling

`CodeBlock` relies on the WonDesign tokens, especially the code font. To
change the look of every code block across your app, redeclare those tokens.
For their names, refer to
[Design Tokens](/styling/tokens/design-tokens#font-family). To change a
single code block's look beyond its props, pass `className` or `style`.

---

## Known Issues

- 🐞 **Only web languages**: Only the languages in Shiki's
  [web bundle](https://shiki.style/guide/bundles#shiki-bundle-web) are
  highlighted, so code in others, like Rust or Go, shows as plain text.
