import { IconButton } from "@wondesign/ui/buttons";
import { Spinner } from "@wondesign/ui/loading";
import { Preview } from "@/widgets/preview";
import { GithubLogo } from "@/shared/ui/Logos";

# Examples

This page explains what each prop of `IconButton` does. Each example shows
the rendered result, followed by its code. The examples below, except the
ones under Sizes, use a size of `20` instead of the default `"1em"`.

---

## Content

Pass an `icon` name from [`@wondesign/icons`](/components/icons/app-icon/overview#icon-list),
or your own content as `children`, like a logo. Passing both is a type
error:

<Preview>
  <IconButton icon="package" size={20} aria-label="Packages" />
  <IconButton aria-label="GitHub">
    <GithubLogo size={20} />
  </IconButton>
</Preview>

```tsx
<IconButton icon="package" aria-label="Packages" />

<IconButton aria-label="GitHub">
  <GithubLogo />
</IconButton>
```

- 📌 **`size` is ignored with `children`.** Size your own content yourself.

---

## Appearance

The `appearance` property sets how much the button stands out, from a solid
background to none until hovered. `"outlined"` is the default:

<Preview>
  <IconButton icon="copy" size={20} appearance="filled" aria-label="Copy" />
  <IconButton icon="copy" size={20} appearance="outlined" aria-label="Copy" />
  <IconButton icon="copy" size={20} appearance="ghost" aria-label="Copy" />
</Preview>

```tsx
<IconButton icon="copy" appearance="filled" aria-label="Copy" />
<IconButton icon="copy" appearance="outlined" aria-label="Copy" />
<IconButton icon="copy" appearance="ghost" aria-label="Copy" />
```

### Rounded

Pass `rounded` to make the button a circle:

<Preview>
  <IconButton icon="download" size={20} aria-label="Download" />
  <IconButton icon="download" size={20} rounded aria-label="Download" />
</Preview>

```tsx
<IconButton icon="download" aria-label="Download" />
<IconButton icon="download" rounded aria-label="Download" />
```

---

## Sizes

The `size` property sets the size of the icon, as any CSS length, or a
number in pixels. `"1em"` is the default, so the icon follows the font size
around it:

<Preview>
  <IconButton icon="bell" aria-label="Notifications" />
  <IconButton icon="bell" size={24} aria-label="Notifications" />
  <IconButton icon="bell" size="2rem" aria-label="Notifications" />
</Preview>

```tsx
<IconButton icon="bell" aria-label="Notifications" />
<IconButton icon="bell" size={24} aria-label="Notifications" />
<IconButton icon="bell" size="2rem" aria-label="Notifications" />
```

### Spacious

Pass `spacious` to give the icon more room, for a larger click target. It
works well with larger icons, which look cramped in the default padding:

<Preview>
  <IconButton icon="palette" size={20} aria-label="Change theme" />
  <IconButton icon="palette" size={20} spacious aria-label="Change theme" />
  <IconButton icon="palette" size="2rem" aria-label="Change theme" />
  <IconButton icon="palette" size="2rem" spacious aria-label="Change theme" />
</Preview>

```tsx
<IconButton icon="palette" aria-label="Change theme" />
<IconButton icon="palette" spacious aria-label="Change theme" />
<IconButton icon="palette" size="2rem" aria-label="Change theme" />
<IconButton icon="palette" size="2rem" spacious aria-label="Change theme" />
```

## Loading

Pass `isLoading` while an action is in progress. Presses are blocked, the
button fades slightly, and a [Spinner](/components/loading/spinner) the size
of the icon takes its place, so the button keeps its size. Pass `fallback` to
show your own content instead, like a different spinner appearance:

<Preview>
  <IconButton icon="upload" size={20} aria-label="Upload" />
  <IconButton icon="upload" size={20} isLoading aria-label="Upload" />
  <IconButton
    icon="upload"
    size={20}
    isLoading
    fallback={<Spinner appearance="tail" size={20} />}
    aria-label="Upload"
  />
</Preview>

```tsx
import { Spinner } from "@wondesign/loading/Spinner";

<IconButton icon="upload" aria-label="Upload" />
<IconButton icon="upload" isLoading aria-label="Upload" />
<IconButton
  icon="upload"
  isLoading
  fallback={<Spinner appearance="tail" size="1em" />}
  aria-label="Upload"
/>
```

- 📌 **A custom fallback isn't sized for you.** Set its size to match the
  icon, or it may be larger than the button's content.

---

## Disabled

Pass `isDisabled` to block presses. By default, the button fades while
disabled:

<Preview>
  <IconButton icon="check" size={20} aria-label="Mark as done" />
  <IconButton icon="check" size={20} isDisabled aria-label="Mark as done" />
</Preview>

```tsx
<IconButton icon="check" aria-label="Mark as done" />
<IconButton icon="check" isDisabled aria-label="Mark as done" />
```
