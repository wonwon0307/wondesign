# IconButton

`IconButton` is a compact button with a single icon, like a copy or close
button. It builds on [Pressable](/components/buttons/pressable).

For a real link that goes to another page, like a link to GitHub, use
[IconLink](/components/links/icon-link) from `@wondesign/links` instead. For
a button with a label, use [Button](/components/buttons/button) instead.

```tsx
import { IconButton } from "@wondesign/buttons/IconButton";
// or
import { IconButton } from "@wondesign/ui/buttons";
```

---

## Key Features

- ✅ **Built-in Icons**: Pass an icon name, and the icon is rendered for you
- ✅ **Your Own Content**: Or pass any content, like your own icon
- ✅ **Three Appearances**: Filled, outlined or ghost, for how much the button stands out
- ✅ **Any Size**: Follows the text around it, or takes the size you set
- ✅ **Rounded or Spacious**: Make the button a circle, or give the icon more room
- ✅ **Loading Spinner**: Shows a spinner while loading, without changing the button's size

---

## Usage

`IconButton` helps you render an icon-only button quickly, using its props. Pass
an icon name from [`@wondesign/icons`](/components/icons/app-icon/overview#icon-list)
as `icon`, and set the look with props like `appearance` and `rounded`. While an action
runs, pass `isLoading` to show a spinner. `children` also accepts your own
content in place of `icon`, like a logo. For what each prop does, refer to
the [Examples tab](/components/buttons/icon-button/examples).

<Preview>
  <IconButton icon="bell" aria-label="Notifications" />
  <IconButton icon="download" appearance="filled" rounded aria-label="Download" />
  <IconButton icon="upload" isLoading aria-label="Upload" />
</Preview>

```tsx
<IconButton icon="bell" aria-label="Notifications" />
<IconButton icon="download" appearance="filled" rounded aria-label="Download" />
<IconButton icon="upload" isLoading aria-label="Upload" />
```

- 📌 Give every icon button an `aria-label` that says what it does, like
  "Notifications". Without one, **the button has no name**, so screen reader
  users can't tell what it does.

For every prop and data attribute, refer to the
[API tab](/components/buttons/icon-button/api).
