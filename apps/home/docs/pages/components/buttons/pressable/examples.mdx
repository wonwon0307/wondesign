# Examples

This page explains what each prop of `Pressable` does. Each example shows the
rendered result, followed by its code.

---

## Disabled

Pass `isDisabled` to block presses. The pointer cursor turns into a
not-allowed cursor:

<Preview>
  <Badge label="Static" />
  <Pressable isDisabled>
    <Badge label="Disabled" />
  </Pressable>
</Preview>

```tsx
// without Pressable
<Badge label="Static" />

// disabled
<Pressable isDisabled>
  <Badge label="Disabled" />
</Pressable>
```

- 📌 **The content doesn't look disabled.** Style it yourself with
  `[data-disabled]`.

---

## Loading

Pass `isLoading` while an action is in progress. Presses are blocked, and the
pointer cursor turns into a progress cursor:

<Preview>
  <Badge label="Static" />
  <Pressable isLoading>
    <Badge label="Loading" />
  </Pressable>
</Preview>

```tsx
// without Pressable
<Badge label="Static" />

// loading
<Pressable isLoading>
  <Badge label="Loading" />
</Pressable>
```

- 📌 **The content doesn't look like it's loading.** Style it yourself with
  `[data-loading]`.
