# Pressable

`Pressable` makes anything inside it clickable, like a card or an image, by
wrapping it in a `<button>`. It builds on
[Headless Button](/headless/button).

Use it to make anything clickable when none of
[Button](/components/buttons/button),
[IconButton](/components/buttons/icon-button) and
[LinkButton](/components/buttons/link-button) fits. It adds only a pointer
cursor and a focus outline, so your content looks the same.

```tsx
import { Pressable } from "@wondesign/buttons/Pressable";
// or
import { Pressable } from "@wondesign/ui/buttons";
```

---

## Key Features

- ✅ **No Default Look**: Your content looks the same, with only a pointer cursor and a focus outline added
- ✅ **Disabled and Loading States**: Presses are blocked, and the button stays focusable
- ✅ **Safe in Forms**: Doesn't submit a form unless you ask it to
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`Pressable` helps you make your own content clickable, without changing how
it looks. Wrap the content in it, and pass `onClick`. For what each prop
does, refer to the [Examples tab](/components/buttons/pressable/examples).

<Preview>
  <Badge label="Static" />
  <Pressable>
    <Badge label="Pressable" />
  </Pressable>
</Preview>

```tsx
// without Pressable
<Badge label="Static" />

// with Pressable
<Pressable onClick={toggle}>
  <Badge label="Pressable" />
</Pressable>
```

For every prop and data attribute, refer to the
[API tab](/components/buttons/pressable/api).

---

## Watch Out

- ⚠️ **Rounded content**: The focus outline follows the corners of the
  `Pressable`, not of your content, so **it has square corners around rounded
  content**. Set a matching `border-radius` on the `Pressable`.
