# LinkButton

`LinkButton` is a button that looks like a link, for actions within a
sentence, like "Show more" or "Undo". It builds on
[Pressable](/components/buttons/pressable).

For a real link that goes to another page, use
[Hyperlink](/components/links/hyperlink) from `@wondesign/links` instead. For an action that stands on its own, like
"Save", use [Button](/components/buttons/button) instead.

```tsx
import { LinkButton } from "@wondesign/buttons/LinkButton";
// or
import { LinkButton } from "@wondesign/ui/buttons";
```

---

## Key Features

- ✅ **Looks Like a Link**: Sits within a sentence, in the primary color, and is underlined on hover
- ✅ **Acts Like a Button**: Screen readers announce it as a button, since it runs an action
- ✅ **Disabled and Loading States**: Presses are blocked, and the button stays focusable

---

## Usage

`LinkButton` helps you add an action within a sentence. Pass the label as
`children`, and place it inside your text. Its label stays on one line, so
it never breaks across two. For what each prop does, refer to the
[Examples tab](/components/buttons/link-button/examples).

<Preview orientation="vertical">
  <p>
    {"Your changes were saved. "}
    <LinkButton>{"Undo"}</LinkButton>
  </p>
</Preview>

```tsx
<p>
  Your changes were saved. <LinkButton onClick={undo}>Undo</LinkButton>
</p>
```

For every prop and data attribute, refer to the
[API tab](/components/buttons/link-button/api).
