# Examples

This page explains what each prop of `LinkButton` does. Each example shows
the rendered result, followed by its code.

---

## Disabled

Pass `isDisabled` to block presses. The button fades, and isn't underlined
on hover:

<Preview>
  <LinkButton>Show more</LinkButton>
  <LinkButton isDisabled>Show more</LinkButton>
</Preview>

```tsx
<LinkButton>Show more</LinkButton>
<LinkButton isDisabled>Show more</LinkButton>
```

---

## Loading

Pass `isLoading` while an action is in progress. Presses are blocked, and the
button fades slightly. There's no spinner, so it still fits within a
sentence:

<Preview>
  <LinkButton>Load replies</LinkButton>
  <LinkButton isLoading>Load replies</LinkButton>
</Preview>

```tsx
<LinkButton>Load replies</LinkButton>
<LinkButton isLoading>Load replies</LinkButton>
```
