import { Button } from "@wondesign/ui/buttons";
import { AppIcon } from "@wondesign/ui/icons";
import { Spinner } from "@wondesign/ui/loading";
import { Preview } from "@/widgets/preview";

# Examples

This page explains what each prop of `Button` does. Each example shows the
rendered result, followed by its code.

---

## Appearance

Pick the colors with `variant`, and choose between a solid background and a
border with `outlined`.

### Variants

The `variant` property sets the colors for the kind of action. It's
`"primary"` by default:

<Preview>
  <Button variant="primary">Primary</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="destructive">Destructive</Button>
</Preview>

```tsx
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="destructive">Destructive</Button>
```

### Outlined

Pass `outlined` to swap the solid background for a border, for less
prominent actions:

<Preview>
  <Button variant="primary" outlined>
    {"Primary"}
  </Button>
  <Button variant="secondary" outlined>
    {"Secondary"}
  </Button>
  <Button variant="destructive" outlined>
    {"Destructive"}
  </Button>
</Preview>

```tsx
<Button variant="primary" outlined>Primary</Button>
<Button variant="secondary" outlined>Secondary</Button>
<Button variant="destructive" outlined>Destructive</Button>
```

---

## Sizes

The `size` property sets the font size, the padding and the space between
the label and the content on either side. It's `"medium"` by default:

<Preview>
  <Button size="small">Small</Button>
  <Button size="medium">Medium</Button>
  <Button size="large">Large</Button>
</Preview>

```tsx
<Button size="small">Small</Button>
<Button size="medium">Medium</Button>
<Button size="large">Large</Button>
```

### Stretch

Pass `stretch` to make the button as wide as its container (`100%`), like the
buttons at the bottom of a form. Buttons in the same row share the width. It
works with every `size`:

<Preview>
  <Button stretch variant="secondary" outlined>
    {"Cancel"}
  </Button>
  <Button stretch>Save</Button>
</Preview>

```tsx
<div style={{ display: "flex", gap: "var(--spacing-md)" }}>
  <Button stretch variant="secondary" outlined>
    Cancel
  </Button>
  <Button stretch>Save</Button>
</div>
```

---

## Content

Add content around the label with `left` and `right`, or pass your own
elements as `children`.

### Left and Right

Pass `left` or `right` to add content on either side of the label, like an
icon:

<Preview>
  <Button left={<AppIcon icon="download" />}>Download</Button>
  <Button right={<AppIcon icon="chevron-right" />}>Next</Button>
</Preview>

```tsx
import { AppIcon } from "@wondesign/icons";

<Button left={<AppIcon icon="download" />}>Download</Button>
<Button right={<AppIcon icon="chevron-right" />}>Next</Button>
```

### Your Own Content

`children` also accepts your own elements, alongside the label. The button is
positioned, so they can be placed against its edges, like a dot for unread
messages:

<Preview>
  <Button variant="secondary" outlined>
    {"Inbox"}
    <span
      style={{
        position: "absolute",
        top: "-4px",
        right: "-4px",
        width: "8px",
        height: "8px",
        borderRadius: "50%",
        background: "var(--color-error)",
      }}
    />
  </Button>
</Preview>

```tsx
<Button variant="secondary" outlined>
  Inbox
  <span className="unread-dot" />
</Button>
```

## Loading

Pass `isLoading` while an action is in progress, like saving a form. Presses
are blocked, the button fades slightly, and a
[Spinner](/components/loading/spinner) takes the place of the label. The
button keeps its size, so the layout around it doesn't move:

<Preview>
  <Button>Save</Button>
  <Button isLoading>Save</Button>
</Preview>

```tsx
<Button isLoading={isSaving} onClick={save}>
  Save
</Button>
```

### Fallback Position

The `fallbackPosition` property sets where the spinner goes. It's
`"replace"` by default, which hides the label. `"left"` keeps the label, and
puts the spinner on its left:

<Preview>
  <Button isLoading fallbackPosition="replace">
    {"Save"}
  </Button>
  <Button isLoading fallbackPosition="left">
    {"Saving"}
  </Button>
</Preview>

```tsx
<Button isLoading fallbackPosition="replace">Save</Button>
<Button isLoading fallbackPosition="left">Saving</Button>
```

With `"left"`, the spinner takes the place of the `left` content while
loading, like an icon that turns into a spinner:

<Preview>
  <Button fallbackPosition="left" left={<AppIcon icon="upload" />}>
    {"Upload"}
  </Button>
  <Button isLoading fallbackPosition="left" left={<AppIcon icon="upload" />}>
    {"Upload"}
  </Button>
</Preview>

```tsx
<Button
  isLoading={isUploading}
  fallbackPosition="left"
  left={<AppIcon icon="upload" />}
>
  Upload
</Button>
```

- 📌 With `"left"` and no `left` content, **the button grows by the
  spinner's width** while loading. Use `"replace"` when the button must keep
  its size.

### Custom Fallback

Pass `fallback` to show your own content instead of the default spinner,
like a different spinner appearance:

<Preview>
  <Button isLoading fallback={<Spinner appearance="tail" />}>
    {"Save"}
  </Button>
  <Button isLoading fallback={<Spinner appearance="bubble" />}>
    {"Save"}
  </Button>
</Preview>

```tsx
import { Spinner } from "@wondesign/loading/Spinner";

<Button isLoading fallback={<Spinner appearance="tail" />}>Save</Button>
<Button isLoading fallback={<Spinner appearance="bubble" />}>Save</Button>
```

- 📌 With `"replace"`, **a fallback wider than the label spills out of the
  button**, since the button keeps the label's size. Keep it short, like an
  icon.

---

## Disabled

Pass `isDisabled` to block presses. By default, the button fades while
disabled:

<Preview>
  <Button>Save</Button>
  <Button isDisabled>Save</Button>
</Preview>

```tsx
<Button isDisabled>Save</Button>
```
