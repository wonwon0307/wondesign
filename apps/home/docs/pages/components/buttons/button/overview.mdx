# Button

`Button` is a form button: a labelled button for actions on a page or in a
form, like "Save" or "Delete". It builds on
[Pressable](/components/buttons/pressable), and adds variants, sizes and a
loading spinner.

To make anything else pressable, like a card or an image, use
[Pressable](/components/buttons/pressable) instead. To go to another page,
like "Sign up" or "Back", use [FormLink](/components/links/form-link) from
`@wondesign/links` instead.

```tsx
import { Button } from "@wondesign/buttons/Button";
// or
import { Button } from "@wondesign/ui/buttons";
```

---

## Key Features

- ✅ **Three Variants**: Primary, secondary and destructive, for the kind of action
- ✅ **Filled or Outlined**: A solid background, or a border for less prominent actions
- ✅ **Three Sizes**: Small, medium and large, or as wide as its container
- ✅ **Left and Right Slots**: Add an icon or other content on either side of the label
- ✅ **Loading Spinner**: Shows a spinner while loading, without changing the button's size
- ✅ **Disabled State**: Presses are blocked, and the button stays focusable

---

## Usage

`Button` helps you render a form button quickly, using its props. Pass the
label as `children`, and set the look with props like `variant` and
`outlined`. While an action runs, pass `isLoading` to show a spinner.
`children` also accepts any elements, for cases where a plain label isn't
enough. For what each prop does, refer to the
[Examples tab](/components/buttons/button/examples).

<Preview>
  <Button variant="primary">Save</Button>
  <Button variant="destructive" outlined>
    {"Delete"}
  </Button>
  <Button isLoading fallbackPosition="left">
    {"Submit"}
  </Button>
</Preview>

```tsx
<Button variant="primary">Save</Button>
<Button variant="destructive" outlined>Delete</Button>
<Button isLoading fallbackPosition="left">Submit</Button>
```

`Button` is mainly for forms, but its `type` is `"button"` by default, so it
doesn't submit a form by accident. To submit a form, pass `type="submit"`
yourself:

```tsx
<form onSubmit={handleSubmit}>
  {/* … */}
  <Button type="submit">Send</Button>
</form>
```

For every prop and data attribute, refer to the
[API tab](/components/buttons/button/api).
