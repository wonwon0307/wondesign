<Callout variant="warning" title="Requires React 19">

---

## Key Features

- ✅ **Decorative or Semantic**: A divider for the layout, or a theme break that screen readers announce
- ✅ **Three Appearances**: Solid, dashed and dotted lines
- ✅ **Any Color**: Pass any CSS color or token for the line
- ✅ **Two Weights**: A regular line, or a bold one for stronger breaks
- ✅ **Styleable**: Your `className` and `style` are applied on top of the defaults

---

## Components

The components differ in whether screen readers announce them.

- ⭐ **[Divider](/components/separators/divider)** — a decorative line, with
  an optional label.
- ⭐ **[ThemeBreak](/components/separators/theme-break)** — a line that marks a
  real change of topic.
