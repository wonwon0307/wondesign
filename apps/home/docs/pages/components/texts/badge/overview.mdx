# Badge

`Badge` is a short label in a colored pill, like a status, a category or a
count.

```tsx
import { Badge } from "@wondesign/texts/Badge";
// or
import { Badge } from "@wondesign/ui/texts";
```

---

## Key Features

- ✅ **Any Color**: Pass any CSS color or token, and the background is tinted to match
- ✅ **Three Sizes**: Small, medium and large, to match the text next to it
- ✅ **Bold Option**: Make the label bolder, for a badge that should stand out
- ✅ **Inline**: Sits in a line of text, a table cell or next to a title
- ✅ **Left and Right Slots**: Add an icon or a count on either side of the label

---

## Usage

`Badge` helps you label something quickly, using its props. Pass the text as
`label`, and set its look with props like `color` and `size`. The background
follows the `color`. For what each prop does, refer to the
[Examples tab](/components/texts/badge/examples).

<Preview>
  <Badge label="Draft" />
  <Badge label="Active" color="var(--color-success)" />
  <Badge label="Failed" color="var(--color-error)" size="small" />
</Preview>

```tsx
<Badge label="Draft" />
<Badge label="Active" color={tokens.colors.success} />
<Badge label="Failed" color={tokens.colors.error} size="small" />
```

To change a badge's look beyond its props, pass `className` or `style`. For
details, refer to [Styling the Components](/components#styling-the-components).
For every prop, refer to the [API tab](/components/texts/badge/api).

- 📌 Pass the text as `label`, since **`children` are ignored**.
- 📌 **`color` and `backgroundColor` in `style` are ignored**, since the
  `color` and `backgroundColor` props always win.
