import { AppIcon } from "@wondesign/ui/icons";
import { Badge } from "@wondesign/ui/texts";
import { colorWithFade } from "@wondesign/ui/tokens";
import { Preview } from "@/widgets/preview";

# Examples

This page explains what each prop of `Badge` does. Each example shows the
rendered result, followed by its code.

---

## Appearance

Pick the colors with `color` and `backgroundColor`, and the weight with
`bold`.

### Colors

The `color` property sets the text color, as any CSS color, including a
token. The default is the muted text color. The `backgroundColor` property sets the
background, and it defaults to the text color at 18% opacity. Set it
yourself for a solid color, or a solid tint of the text color made with
[`colorWithFade`](/styling/tokens/api#colorwithfade):

<Preview>
  <Badge label="Draft" />
  <Badge label="Active" color="var(--color-success)" />
  <Badge label="New" color="white" backgroundColor="var(--color-primary)" />
  <Badge
    label="Active"
    color="var(--color-success)"
    backgroundColor={colorWithFade("var(--color-success)", 0.15)}
  />
</Preview>

```tsx
import { colorWithFade, tokens } from "@wondesign/tokens";

// the default colors
<Badge label="Draft" />

// a text color, with the default background
<Badge label="Active" color={tokens.colors.success} />

// a solid background
<Badge label="New" color="white" backgroundColor={tokens.colors.primary} />

// a solid tint of the text color
<Badge
  label="Active"
  color={tokens.colors.success}
  backgroundColor={colorWithFade(tokens.colors.success, 0.15)}
/>
```

- 📌 The default background is translucent, so **the surface behind a badge
  shows through it**. Pass a solid `backgroundColor` for badges on colored
  surfaces.

### Bold

Pass `bold` to make the label bolder, for a badge that should stand out
more:

<Preview>
  <Badge label="Beta" color="var(--color-primary)" />
  <Badge label="Beta" color="var(--color-primary)" bold />
</Preview>

```tsx
<Badge label="Beta" color={tokens.colors.primary} />
<Badge label="Beta" color={tokens.colors.primary} bold />
```

---

## Sizes

The `size` property sets the font size and the padding together. It's
`"medium"` by default:

<Preview>
  <Badge label="Large" size="large" />
  <Badge label="Medium" size="medium" />
  <Badge label="Small" size="small" />
</Preview>

```tsx
<Badge label="Large" size="large" />
<Badge label="Medium" size="medium" />
<Badge label="Small" size="small" />
```

---

## Left and Right

Pass `left` or `right` to add content on either side of the label, like an
icon or a count:

<Preview>
  <Badge
    label="Verified"
    color="var(--color-success)"
    left={<AppIcon icon="check" />}
  />
  <Badge label="Inbox" right={<span>12</span>} />
</Preview>

```tsx
import { AppIcon } from "@wondesign/icons";

<Badge label="Verified" color={tokens.colors.success} left={<AppIcon icon="check" />} />
<Badge label="Inbox" right={<span>12</span>} />
```
