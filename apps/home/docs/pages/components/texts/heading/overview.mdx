# Heading

`Heading` is a page or section title, from `<h1>` to `<h6>`, on the type
scale.

Use it only for titles. Every heading is part of the page's outline, so
**screen reader users hear it as a section title**. For text that only needs
to look big, use another component.

```tsx
import { Heading } from "@wondesign/texts/Heading";
// or
import { Heading } from "@wondesign/ui/texts";
```

---

## Key Features

- ✅ **Six Levels**: Each level renders its own heading element, at its own size
- ✅ **Custom Styles**: Apply your own styles to any level
- ✅ **Single Line by Default**: Long titles are cut off with an ellipsis, or after as many lines as you like
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`Heading` helps you render a title quickly, using its props. Pass the title
as `children`, and pick a `level` that fits the page's outline, which sets
the element.
To make it a step larger or smaller, pass `size`. Long titles are cut off
after one line, and `maxNumLines` allows more. For
what each prop does, refer to the
[Examples tab](/components/texts/heading/examples).

<Preview orientation="vertical">
  <Heading level={3}>{"Settings"}</Heading>
  <Heading level={4}>{"Billing"}</Heading>
</Preview>

```tsx
<Heading level={3}>Settings</Heading>
<Heading level={4}>Billing</Heading>
```

For every prop, refer to the [API tab](/components/texts/heading/api).

---

## Styling

`Heading` relies mostly on the WonDesign typography tokens. To change the
look of every heading across your app, redeclare those tokens. For their
names, refer to [Design Tokens](/styling/tokens/design-tokens#typography). To
change a single heading's look beyond its props, pass `className` or `style`.
