# Examples

This page explains what each prop of `Heading` does. Each example shows the
rendered result, followed by its code.

---

## Levels

The `level` property picks the element, from `level={1}` for an `<h1>` down
to `level={6}` for an `<h6>`. Pick the level that fits the page's outline.
Each level has its own size, and the size gets smaller as the level goes
down:

<Preview orientation="vertical">
  <Heading level={1}>{"Settings"}</Heading>
  <Heading level={2}>{"Billing"}</Heading>
  <Heading level={3}>{"Payment Methods"}</Heading>
  <Heading level={4}>{"Saved Cards"}</Heading>
  <Heading level={5}>{"Visa ending in 4242"}</Heading>
  <Heading level={6}>{"Billing Address"}</Heading>
</Preview>

```tsx
<Heading level={1}>Settings</Heading>
<Heading level={2}>Billing</Heading>
<Heading level={3}>Payment Methods</Heading>
<Heading level={4}>Saved Cards</Heading>
<Heading level={5}>Visa ending in 4242</Heading>
<Heading level={6}>Billing Address</Heading>
```

- 📌 **Don't pick a level for its size.** Pick it for the outline, and change
  the look with `size`, `className` or `style`.

### Size

The `size` property takes the look of the level next to it, without changing
the element. `"larger"` looks like the level above, and `"smaller"` like the
level below. It's `"normal"` by default:

<Preview orientation="vertical">
  <Heading level={4} size="larger">
    {"Larger, but still an h4"}
  </Heading>
  <Heading level={4}>{"Normal h4"}</Heading>
  <Heading level={4} size="smaller">
    {"Smaller, but still an h4"}
  </Heading>
</Preview>

```tsx
// an <h4>, at the size of level 3
<Heading level={4} size="larger">Larger, but still an h4</Heading>

// an <h4>, at its own size
<Heading level={4}>Normal h4</Heading>

// an <h4>, at the size of level 5
<Heading level={4} size="smaller">Smaller, but still an h4</Heading>
```

- 📌 **`"larger"` does nothing at level 1, and `"smaller"` does nothing at
  level 6**, since there's no level beyond them.

## Line Clamping

A heading is **cut off after one line by default**, with an ellipsis. Pass
`maxNumLines` to allow more lines, or `0` to show every line. The cut-off text
is still on the page, so **screen readers read the whole title**, even though
it isn't shown on screen:

<Preview orientation="vertical">
  <Heading level={4}>
    {
      "A long title that's cut off after one line, because that's the default for every heading, whatever its level"
    }
  </Heading>
  <Heading level={4} maxNumLines={2}>
    {
      "A long title that's allowed to wrap onto a second line, but is cut off there, even if there's more text left to show after it, like the rest of this sentence and everything after it"
    }
  </Heading>
  <Heading level={4} maxNumLines={0}>
    {
      "A long title that's never cut off, so it wraps onto as many lines as it needs to show every single word, however long the title gets and however narrow its container is, from the first word right through to this one"
    }
  </Heading>
</Preview>

```tsx
// cut off after one line, the default
<Heading level={4}>A long title…</Heading>

// cut off after two lines
<Heading level={4} maxNumLines={2}>
  A long title…
</Heading>

// never cut off
<Heading level={4} maxNumLines={0}>
  A long title…
</Heading>
```

- 📌 A long word or URL is broken onto the next line, instead of running past
  the edge.
- 📌 While clamped, setting `display`, `overflow`, `text-overflow` or
  `-webkit-box-orient` yourself **would break the clamping without an
  error**.
