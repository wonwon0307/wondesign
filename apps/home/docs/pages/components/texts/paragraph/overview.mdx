# Paragraph

`Paragraph` is the main body text of a page, a section or a card, from a
single sentence to several paragraphs.

For supporting text, like a field hint or a caption, use
[Description](/components/texts/description) instead.

```tsx
import { Paragraph } from "@wondesign/texts/Paragraph";
// or
import { Paragraph } from "@wondesign/ui/texts";
```

---

## Key Features

- ✅ **Three Sizes**: Small, medium and large, on the type scale
- ✅ **Two Tones**: Default and muted colors
- ✅ **Selectable Element**: Render it as a `<p>`, `<div>` or `<span>`
- ✅ **Line Clamping**: Cut long text off after as many lines as you like
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`Paragraph` helps you render body text quickly, using its props. Pass the
text as `children`, and set its look with props like `size` and `tone`. For
what each prop does, refer to the
[Examples tab](/components/texts/paragraph/examples).

<Preview orientation="vertical">
  <Heading level={3}>{"Getting Started"}</Heading>
  <Paragraph>
    {"Create a project, invite your team and connect your first data source."}
  </Paragraph>
  <Paragraph>{"Each step takes only a few minutes."}</Paragraph>
</Preview>

```tsx
<Heading level={3}>Getting Started</Heading>
<Paragraph>
  Create a project, invite your team and connect your first data source.
</Paragraph>
<Paragraph>Each step takes only a few minutes.</Paragraph>
```

For every prop, refer to the [API tab](/components/texts/paragraph/api).

---

## Styling

`Paragraph` relies mostly on the WonDesign typography tokens. To change the
look of every paragraph across your app, redeclare those tokens. For their
names, refer to [Design Tokens](/styling/tokens/design-tokens#typography). To
change a single paragraph's look beyond its props, pass `className` or
`style`.
