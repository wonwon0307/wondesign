import { Description, Heading } from "@wondesign/ui/texts";
import { Preview } from "@/widgets/preview";

# Examples

This page explains what each prop of `Description` does. Each example shows
the rendered result, followed by its code.

---

## Appearance

Pick the font size with `size`, and the color with `tone`.

### Sizes

The `size` property sets the font size. It's `"medium"` by default:

<Preview orientation="vertical">
  <Description size="large">
    {"Large, for a summary right below a page title."}
  </Description>
  <Description size="medium">
    {"Medium, for field hints and summaries."}
  </Description>
  <Description size="small">{"Small, for captions and metadata."}</Description>
</Preview>

```tsx
<Description size="large">
  Large, for a summary right below a page title.
</Description>
<Description size="medium">Medium, for field hints and summaries.</Description>
<Description size="small">Small, for captions and metadata.</Description>
```

### Tones

The `tone` property sets the color, with four options. Without it, the
description uses `"default"`, the same color as body text, for a description
that's read like any other text, like a page summary:

<Preview orientation="vertical">
  <Heading level={3}>{"Billing"}</Heading>
  <Description>{"Manage your plan, payment methods and invoices."}</Description>
</Preview>

```tsx
<Heading level={3}>Billing</Heading>
<Description>Manage your plan, payment methods and invoices.</Description>
```

`"muted"` uses a lighter color, for text that should step back, like
metadata:

<Preview orientation="vertical">
  <Heading level={4}>{"Quarterly Report"}</Heading>
  <Description size="small" tone="muted">
    {"Last edited 3 days ago by Alex"}
  </Description>
</Preview>

```tsx
<Heading level={4}>Quarterly Report</Heading>
<Description size="small" tone="muted">
  Last edited 3 days ago by Alex
</Description>
```

`"success"` and `"danger"` use the success and error colors, for something
that went right or wrong, like a field check:

<Preview orientation="vertical">
  <input
    type="text"
    defaultValue="wondesign"
    style={{
      padding: "var(--spacing-xs) var(--spacing-sm)",
      border: "1px solid var(--color-border)",
      borderRadius: "var(--radius-sm)",
    }}
  />
  <Description size="small" tone="success">
    {"Username is available."}
  </Description>
  <input
    type="password"
    defaultValue="hunter2"
    style={{
      padding: "var(--spacing-xs) var(--spacing-sm)",
      border: "1px solid var(--color-border)",
      borderRadius: "var(--radius-sm)",
    }}
  />
  <Description size="small" tone="danger">
    {"Password must be at least 12 characters."}
  </Description>
</Preview>

```tsx
<input type="text" />
<Description size="small" tone="success">
  Username is available.
</Description>

<input type="password" />
<Description size="small" tone="danger">
  Password must be at least 12 characters.
</Description>
```

## Element

Pass `as` to render the element that fits where it's used. It renders a
`<p>` by default, and the other options are `"span"`, `"div"`, `"figcaption"`
and `"dd"`:

<Preview orientation="vertical">
  <dl
    style={{
      display: "grid",
      gridTemplateColumns: "auto 1fr",
      gap: "var(--spacing-xs) var(--spacing-md)",
    }}
  >
    <dt style={{ fontWeight: 600 }}>{"Status"}</dt>
    <Description as="dd" tone="muted">
      {"Active"}
    </Description>
    <dt style={{ fontWeight: 600 }}>{"Created"}</dt>
    <Description as="dd" tone="muted">
      {"Oct 26"}
    </Description>
  </dl>
</Preview>

```tsx
<dl>
  <dt>Status</dt>
  <Description as="dd" tone="muted">
    Active
  </Description>
  <dt>Created</dt>
  <Description as="dd" tone="muted">
    Oct 26
  </Description>
</dl>
```

## Lines

Set how long the lines run with `lineLength`, how they break with `wrap`, and
how many show with `maxNumLines`. The examples below have a background, to
show where each description ends.

### Line Length

A description starts a new line at about 60 characters (`60ch`), **even when
its container is wider**. Pass a number to `lineLength` for another length in
characters, or `"full"` to run the full width of the container:

<Preview orientation="vertical">
  <Description
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {
      "A description that starts a new line at about 60 characters, so each line stays easy to follow, even when its container is much wider than that."
    }
  </Description>
  <Description
    lineLength={40}
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {
      "A description that starts a new line at about 40 characters, for a narrower column of text."
    }
  </Description>
  <Description
    lineLength="full"
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {
      "A description that runs the full width of its container, however wide that is, before it starts a new line."
    }
  </Description>
</Preview>

```tsx
// starts a new line at 60ch, the default
<Description>A long description…</Description>

// starts a new line at 40ch
<Description lineLength={40}>A long description…</Description>

// runs the full width of the container
<Description lineLength="full">A long description…</Description>
```

- 📌 **A `lineLength` of `0` or less falls back to `"full"`.**

### Wrapping

The `wrap` property sets
[the CSS `text-wrap` property](https://developer.mozilla.org/en-US/docs/Web/CSS/text-wrap),
and it's `"pretty"` by default. Each description below has the same text and
line length:

<Preview orientation="vertical">
  <Description
    lineLength={36}
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {"Manage your plan, payment methods and invoices in one place."}
  </Description>
  <Description
    lineLength={36}
    wrap="balance"
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {"Manage your plan, payment methods and invoices in one place."}
  </Description>
</Preview>

```tsx
<Description lineLength={36}>Manage your plan…</Description>
<Description lineLength={36} wrap="balance">Manage your plan…</Description>
```

### Line Clamping

A description shows every line by default. Pass `maxNumLines` to cut it off
after that many lines, with an ellipsis. The cut-off text is still on the
page, so **screen readers read the whole description**, even though it isn't
shown on screen:

<Preview orientation="vertical">
  <Description
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {
      "A long description that's never cut off, because that's the default, so it wraps onto as many lines as it needs to show every single word, however long it gets. It keeps going onto a third line, and then a fourth, so you can see that nothing is hidden, from the first word right through to the very last one."
    }
  </Description>
  <Description
    maxNumLines={1}
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {
      "A long description that's cut off after one line, even if there's more text left to show after it, like the rest of this sentence and everything that comes after it."
    }
  </Description>
  <Description
    maxNumLines={2}
    style={{
      padding: "var(--spacing-sm)",
      backgroundColor: "var(--color-background-muted)",
    }}
  >
    {
      "A long description that's allowed to wrap onto a second line, but is cut off there, even if there's more text left to show after it, like the rest of this sentence and everything that comes after it."
    }
  </Description>
</Preview>

```tsx
// never cut off, the default
<Description>A long description…</Description>

// cut off after one line
<Description maxNumLines={1}>A long description…</Description>

// cut off after two lines
<Description maxNumLines={2}>A long description…</Description>
```

- 📌 A long word or URL is broken onto the next line, instead of running past
  the edge.
- 📌 While clamped, setting `display`, `overflow`, `text-overflow` or
  `-webkit-box-orient` yourself **would break the clamping without an
  error**.
