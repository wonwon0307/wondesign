# Description

`Description` is supporting text, like a summary of the whole page right
below its `Heading`, a field hint, a caption or a metadata value.

For the main body text of a page, use
[Paragraph](/components/texts/paragraph) instead.

```tsx
import { Description } from "@wondesign/texts/Description";
// or
import { Description } from "@wondesign/ui/texts";
```

---

## Key Features

- ✅ **Three Sizes**: Small, medium and large, on the type scale
- ✅ **Four Tones**: Default, muted, danger and success colors
- ✅ **Readable Lines**: Long text wraps at about 60 characters by default, or at the length you set
- ✅ **Selectable Element**: Render it as a `<p>`, `<span>`, `<div>`, `<figcaption>` or `<dd>`
- ✅ **Line Clamping**: Cut long text off after as many lines as you like
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

---

## Usage

`Description` helps you add supporting text quickly, using its props. Pass
the text as `children`, and set its look with props like `size` and `tone`.
It renders a `<p>` by default, and `as` renders another element. For what
each prop does, refer to the
[Examples tab](/components/texts/description/examples).

<Preview orientation="vertical">
  <Heading level={3}>{"Billing"}</Heading>
  <Description tone="muted">
    {"Manage your plan, payment methods and invoices."}
  </Description>
</Preview>

```tsx
<Heading level={3}>Billing</Heading>
<Description tone="muted">
  Manage your plan, payment methods and invoices.
</Description>
```

For every prop, refer to the [API tab](/components/texts/description/api).

---

## Styling

`Description` relies mostly on the WonDesign typography tokens. To change the
look of every description across your app, redeclare those tokens. For their
names, refer to [Design Tokens](/styling/tokens/design-tokens#typography). To
change a single description's look beyond its props, pass `className` or
`style`.
