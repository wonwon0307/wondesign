# About WonDesign Foundations

**WonDesign Foundations** is the **skeleton for design systems** — the
**low-level infrastructure** that design tokens, theming, a CSS reset, and the
behaviour behind menus, dialogs, tooltips and tabs are built on.

Every app or project ends up redoing the same groundwork: a color palette,
a CSS reset, a set of tokens, focus and keyboard handling. Foundations
standardize that repetitive work into small, focused packages, so it's
done once and you can spend your time on the part that makes your product
look like _yours_.

---

## Philosophy

> **Opinionated logic, unopinionated style.**

Foundations take a strong stance on **behaviour**: where focus goes when a
dialog opens, how a shortkey works across platforms, where floating content
finds room, how a token becomes a CSS variable. They take no stance on
**appearance**. The hooks render nothing, and the default token values are
there to start from, not to keep.

This makes Foundations a **safe dependency for any design system**, whatever
its brand or styling approach. The components built on top of them — unstyled in
[`@wondesign/headless`](/components/headless), and styled in the rest of the
library — live in **[Components](/components/about)**.

## Packages

**Every package stands on its own** — install only the ones you use. None of
them depends on another.

### Primitives

The base layer every app sits on — styles, values and themes.

- 📦 **[`@wondesign/reset-css`](/foundations/reset-css)** — A single stylesheet
  that smooths out browser defaults, so every browser starts from the same
  baseline.
- 📦 **[`@wondesign/tokens`](/foundations/tokens)** — A semantic set of design
  tokens, from colors to spacing, available as CSS variables and a typed
  object, with light and dark palettes and ready-made media queries.
- 📦 **[`@wondesign/theme`](/foundations/theme)** — Light / dark / system or
  named-theme switching for React, saved between visits, synced across tabs,
  and free of first-paint flashes.

### Interactions

React hooks for the behaviour behind interactive components. They hold **no
markup and no styles** — attach them to your own elements.

- 📦 **[`@wondesign/disclosure`](/foundations/disclosure)** — Open / closed state
  for anything that shows and hides, controlled or uncontrolled, and locking
  the page's scroll while it's open.
- 📦 **[`@wondesign/focus`](/foundations/focus)** — Arrow key navigation, moving
  focus in when content opens and back when it closes, focus traps, and
  keeping the background out of reach.
- 📦 **[`@wondesign/key-events`](/foundations/key-events)** — Closing on Escape
  and cross-platform shortkeys like `Mod+K`.
- 📦 **[`@wondesign/pointer`](/foundations/pointer)** — Clicks outside an element
  and long presses, on mouse, touch and pen.
- 📦 **[`@wondesign/position`](/foundations/position)** — Placing floating
  content next to its trigger, keeping it on screen and pointing an arrow back
  at it.

### Utilities

Tools for building a design system, rather than running inside one.

- 📦 **[`@wondesign/svg2tsx`](/foundations/svg2tsx)** — A CLI that turns folders
  of SVG files into typed React icon components.
