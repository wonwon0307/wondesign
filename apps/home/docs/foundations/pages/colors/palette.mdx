# Choosing a Palette

A palette is any object that satisfies `SemanticColors`. There are a few ways
to get one, depending on how much you want to customize.

---

## Use WonDesign Presets

The quickest start is the two ready-made presets that fill in every role:
`wondesignLight` and `wondesignDark`. The two are tuned independently rather
than mirrored — translucent values in particular read differently on a dark
background, so the dark preset's alpha levels are chosen for visibility on
dark surfaces.

In fact, this whole website is built with these two presets — switch your
system between light and dark mode to see both in action. If you like how they
look, you're welcome to use them as they are:

```ts
import { wondesignLight, wondesignDark } from "@wondesign/colors";
```

---

## Adjust a Preset

If a preset is close to what you want, spread it and override only the roles
you care about — a different brand color, for example:

```ts
import { wondesignLight, type SemanticColors } from "@wondesign/colors";

const brandLight: SemanticColors = {
  ...wondesignLight,
  primary: "#7C3AED",
};
```

---

## Bring Your Own Palette

For a fully custom look, write the palette from scratch. `SemanticColors` is a
plain interface, so TypeScript will point out any role you've missed:

```ts
import type { SemanticColors } from "@wondesign/colors";

const brandLight: SemanticColors = {
  primary: "#7C3AED",
  onPrimary: "#FFFFFF",
  // …the remaining 16 roles
};
```

Values are passed through as-is, so anything CSS accepts as a color works —
hex, `rgb()`, `oklch()`.
