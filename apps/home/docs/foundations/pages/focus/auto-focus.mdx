# Auto Focus

`useAutoFocus` moves focus into an element when it opens, and back out when it
closes. It falls back gracefully when it's pointed at an element that can't take
focus. It's helpful for any overlay that needs the user's attention right away,
like menus, dialogs and popovers.

---

## Usage

The hook acts when `enabled` turns `true` or `false`, or when the component
calling it mounts or unmounts. Overlays like menus, dialogs and popovers
come and go the same way, so focus follows them in and out without any extra
wiring.

When `enabled` turns `true`, focus moves to `initialRef`. If it's outside
`targetRef` or can't take focus, **it's ignored as if it wasn't given**, with
no error. Without one, focus moves to the first focusable element inside
`targetRef`, skipping disabled, hidden and inert ones. With nothing focusable
inside, it moves to `targetRef` itself, so give it `tabIndex={-1}`, or **focus
stays where it was**.

When `enabled` turns `false`, or the component unmounts, focus goes back to
`returnRef`. If it points at nothing by then, focus goes back to the element
that had it before `enabled` turned `true`. If focus has already moved outside
`targetRef`, like to an input the user clicked, **it stays there**.

```tsx
import { useRef, useState } from "react";
import { useAutoFocus } from "@wondesign/focus/auto-focus";

export function FilterPopover() {
  const [isOpen, setIsOpen] = useState(true);
  const contentRef = useRef<HTMLDivElement>(null);
  const doneRef = useRef<HTMLButtonElement>(null);
  const searchRef = useRef<HTMLButtonElement>(null);

  useAutoFocus(contentRef, {
    enabled: isOpen,
    initialRef: doneRef,
    returnRef: searchRef,
  });

  return (
    <>
      <button onClick={() => setIsOpen((open) => !open)}>Filters</button>
      {isOpen && (
        <div ref={contentRef} tabIndex={-1}>
          <label>
            <input type="checkbox" /> In stock
          </label>
          <button ref={doneRef} onClick={() => setIsOpen(false)}>
            Done
          </button>
        </div>
      )}
      <button ref={searchRef}>Search</button>
    </>
  );
}
```

- 📌 An element only counts as disabled with the native `disabled` attribute.
  Elements disabled another way, like with `aria-disabled` or a headless
  [Button](/components/headless/button) with `isDisabled`, stay focusable, so
  **focus can land on them**.

---

## API

Import `useAutoFocus` and `UseAutoFocusOptions` from
`@wondesign/focus/auto-focus`. `targetRef` is required, while `options` and
everything in it can be left out. The hook returns nothing — it only moves
focus:

```ts
interface UseAutoFocusOptions {
  // whether focus is moved in. defaults to `false`.
  // pass the open state,
  // so focus moves in on open and back on close.
  enabled?: boolean;

  // where focus moves to on open. must be inside `targetRef`.
  // defaults to the first focusable element inside `targetRef`.
  initialRef?: React.RefObject<HTMLElement | null>;

  // where focus goes back to on close.
  // defaults to the element that had focus before it opened.
  returnRef?: React.RefObject<HTMLElement | null>;
}

function useAutoFocus(
  // the element to move focus into.
  targetRef: React.RefObject<HTMLElement | null>,
  options?: UseAutoFocusOptions,
): void;
```

---

## Watch Out

- ⚠️ **Give a non-interactive `initialRef` `tabIndex={-1}`**: Headings,
  paragraphs and similar elements can't take focus on their own, so without it
  **focus starts on the first focusable element instead**.

- ⚠️ **Pass the open state to `enabled`**: If the element isn't on the page
  all the time, pass its open state to `enabled`. Rendering it conditionally
  is fine, as long as `enabled` turns on together with it. With `enabled`
  always `true`, the hook turns on before the element appears, and **never
  moves focus in**:

  ```tsx
  // ❌ the hook is already on when the popover appears, so it never sees it
  useAutoFocus(contentRef, { enabled: true });

  return isOpen ? <div ref={contentRef}>…</div> : null;
  ```

  ```tsx
  // ✅ the hook turns on together with the popover
  useAutoFocus(contentRef, { enabled: isOpen });

  return isOpen ? <div ref={contentRef}>…</div> : null;
  ```
