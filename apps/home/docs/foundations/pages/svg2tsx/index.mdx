## Key Features

The svg2tsx CLI converts SVG files into React components based on [SVGR](https://react-svgr.com/). The key features are as follows:

- ✅ **Auto Convert**: Automatically converts SVG files to Typescript React components
- ✅ **Duplicate Checks**: Automatically detects duplicate names and contents
- ✅ **Multiple Families**: Convert several independent sets of icons — each with its own source/output directories — in a single run
- ✅ **Platform Independent**: Set options to convert icons for React Native components
- ✅ **Barrel Exports**: Automatically creates the `index.ts` barrel file if needed
- ✅ **Facade Component**: Automatically creates a facade component if needed

## Rules

`svg2tsx` validates your source files and config before converting anything. The rules are as follows:

- ❗️ **kebab-case SVG files** - SVG filenames must be strictly kebab-case (`^[a-z][a-z0-9]*(-[a-z0-9]+)*$`)
- ❗️ **Unique family names** - Family names (set through `entry.name` or `srcDir`'s basename)
must be unique across the whole config. Reusing one throws, even across different array entries.
- ❗️ **Unique icon names** - Icon names must be unique across the whole run as well (not just within a family).
- ❗️ **Unique icon content** - The content within each SVG file must be unique too —
byte-identical SVGs (even under different names) are rejected as duplicates.
- ❗️ **Non-empty family** - Each family must contain at least one `*.svg` file in its `srcDir`.
- ❗️ **Non-empty content** - Icon content cannot be empty.

Any violation aborts the whole run with a message naming the offending file(s) — nothing partial is written.
