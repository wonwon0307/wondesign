# The conversion

Every icon goes through the same pipeline: validate, then run through
[`@svgr/core`](https://react-svgr.com/) under a `svgrOptions` object that
`svg2tsx` mostly pre-fills for you. Some of those pre-filled values are
starting points you're meant to tune per project; others are load-bearing —
they're what makes the output a WonDesign icon component at all, rather
than just "a component SVGR happened to produce."

---

`defineConfig` exists purely for type-checking — it returns its argument
unchanged. The CLI looks for `svg2tsx.config.ts` in the current working
directory by default; pass `-c <path>` to point elsewhere. With no config
file at all, it runs on [defaults](#configuration).

With no `entry` given, svg2tsx scans `assets/` and writes to `src/` under a
default family named `"app"` — which is why the example above is enough to
get a facade named `AppIcon` (see [`entry`](#multiple-families) for how that
name is derived).

The config is loaded with [jiti](https://github.com/unjs/jiti), so a plain
`.ts` file works with no separate build step.
