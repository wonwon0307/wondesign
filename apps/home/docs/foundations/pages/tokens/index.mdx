<PackageInfo name="@wondesign/tokens" relPath="foundations/tokens">
  `@wondesign/tokens` is a token foundation for design systems. It defines a
  fixed, semantic vocabulary (`primary`, `spacing.md`, `radius.lg`, …), exposes
  every token as a CSS variable with a built-in fallback, and ships the defaults
  and a single function to turn your own values into a stylesheet. Just typed
  objects and plain strings — no dependencies, no React.
</PackageInfo>

---

## Installation

```bash
pnpm add @wondesign/tokens
```

## Key Features

- ✅ **Semantic Vocabulary**: Tokens are named by role (`primary`, `surface`, `bodyMedium`, `modal`, …) rather than by value, across seven categories — colors, elevation, opacity, radius, spacing, typography and z-index
- ✅ **CSS Variables with Fallbacks**: Every token resolves to `var(--name, default)`, so styles render correctly even before any values are installed
- ✅ **Typed JavaScript Object**: `tokens` mirrors every variable for CSS-in-JS, vanilla-extract, or inline styles
- ✅ **Build Your Own**: `buildCssVariables` turns any set of token values into a stylesheet string, scoped to any selector
- ✅ **Light & Dark**: `wondesignLight` and `wondesignDark` palettes, merged into CSS `light-dark()` values by `mergeLightDark`
- ✅ **Extendable**: Add your own keys to any category — they become CSS variables named after the key
- ✅ **Color Helpers**: `colorWithFade` and `colorWithOpacity` derive tints and translucent variants with `color-mix()`
- ✅ **Media Queries**: Ready-made breakpoint and hover queries, or build your own with `createBreakpointQueries`
- ✅ **Framework Agnostic**: Every value is a plain string — install the stylesheet in the `<head>` of any framework

```ts
import { tokens, mediaQueries } from "@wondesign/tokens";

tokens.spacing.md; // "var(--spacing-md, 8px)"
tokens.colors.primary; // "var(--color-primary, #1647E8)"

mediaQueries.breakpoints.large; // "screen and (width >= 1280px)"
mediaQueries.hoverable; // "(hover: hover) and (pointer: fine)"
```

Build your own values from the defaults:

```ts
import { buildCssVariables, defaultSpacing } from "@wondesign/tokens";

const css = buildCssVariables({
  spacing: { ...defaultSpacing, md: "10px" },
});
```

## Known Issues

- 🐞 **Modern browsers only**: The tokens rely on `light-dark()`, `color-mix()`, and range media queries (`width >= 768px`), which need **Chrome / Edge 123+, Firefox 120+, or Safari 17.5+**. Older browsers ignore these values, so colors, tints, and responsive styles may not apply at all
- 🐞 **colorWithFade in Next.js**: Colors made with `colorWithFade` may not show, or fall back to an unexpected color, when your build tool rewrites `light-dark()` for older browsers. See [Troubleshooting](/foundations/tokens/troubleshooting) for the fix
