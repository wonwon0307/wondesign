## Key Features

- ✅ **Escape to Close**: `useEscapeKey` runs a callback when the user presses <Keyboard>Esc</Keyboard>
- ✅ **Shortkeys**: `useShortkey` binds shortkeys like <KeyboardGroup shortkey="Mod+K" /> as plain strings, checked by TypeScript
- ✅ **Cross-Platform**: <Keyboard>Mod</Keyboard> means <Keyboard>⌘</Keyboard> on Apple devices and <Keyboard>Ctrl</Keyboard> everywhere else
- ✅ **Safe While Typing**: Shortkeys without <Keyboard>Ctrl</Keyboard> or <Keyboard>⌘</Keyboard> pause while the user types in an input
- ✅ **Ready to Show**: `useShortkeyDisplay` gives a shortkey's keys for the user's platform, without listening for it
- ✅ **Accessible**: Get the `aria-keyshortcuts` value for the control a shortkey triggers
- ✅ **Forgiving**: Inline callbacks work as they are, and holding a key down fires it once

## Upcoming Features

- 🔜 **Layered Escape**: Only the topmost layer closes when several listen for <Keyboard>Esc</Keyboard>
