  `@wondesign/key-events` handles the keyboard interactions that dialogs, menus

---

## Key Features

- ✅ **Escape to Close**: `useEscapeKey` runs a callback when the user presses Escape
- ✅ **Shortkeys**: `useShortkey` binds shortkeys like `Mod+K` as plain strings, checked by TypeScript
- ✅ **Cross-Platform**: `Mod` means ⌘ on Apple devices and Ctrl everywhere else
- ✅ **Safe While Typing**: Shortkeys without Ctrl or ⌘ pause while the user types in an input
- ✅ **Ready to Show**: `useShortkeyDisplay` gives a shortkey's keys for the user's platform, without listening for it
- ✅ **Accessible**: Get the `aria-keyshortcuts` value for the control a shortkey triggers
- ✅ **Forgiving**: Inline callbacks work as they are, and holding a key down fires it once

---

## Upcoming Features

- 🔜 **Layered Escape**: Only the topmost layer closes when several listen for Escape
- 🔜 **Layout-Aware Shortkeys**: Match the key the user sees, not its position on a QWERTY keyboard
