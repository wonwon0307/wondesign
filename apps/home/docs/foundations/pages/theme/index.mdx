## Key Features

- ✅ **Two Ways to Theme**: Pick from a flat list of named themes, or let light / dark / system decide, with one or more themes for each side
- ✅ **Follows the OS**: Can follow the user's OS light / dark setting, even when it changes
- ✅ **Persistence**: The user's choice is saved and re-applied on every visit
- ✅ **Cross-Tab Sync**: Change the theme in one tab, and every other open tab switches with it
- ✅ **No First-Paint Flash**: Prevents quick flashes on the very first paint
- ✅ **Hydration-Safe**: Works with server rendering, without hydration mismatch errors
- ✅ **Plain CSS Hooks**: Style each theme with plain CSS — no runtime styling needed

## Ways to Theme

There are three ways to theme your app, from the simplest to the most
flexible. Pick one per app.

### Light-Dark

A light / dark / system switch. The easiest way to use it is with the
[`@wondesign/tokens` preset](/foundations/tokens/setup): its colors already
have a light and a dark value, so they follow the switch with no extra CSS.

Not using the preset? Write your own colors with CSS's
[`light-dark()`](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value/light-dark)
function, and they follow the switch the same way.

```ts
import { LightDarkProvider } from "@wondesign/theme/light-dark";
```

See [Light-Dark Setup](/foundations/theme/setup#light-dark) to get started.

### Advanced Light-Dark

Light-Dark with more than one theme per side — say, `"light"` and `"paper"`
for light, `"dark"` and `"midnight"` for dark. The user still picks light,
dark, or system, and also picks which theme to use for each side. Style the
extra themes with `data-theme` selectors on top of your light and dark colors.

```ts
import { LightDarkProvider } from "@wondesign/theme/light-dark";
```

See [Advanced Light-Dark Setup](/foundations/theme/setup#advanced-light-dark)
to set it up.

### Named Themes

A flat list of themes — `"ocean"`, `"forest"`, `"sunset"` — with none of them
tied to light or dark. The user picks one, and you style each with
`data-theme` selectors.

```ts
import { ThemeProvider } from "@wondesign/theme";
```

See [Named Themes Setup](/foundations/theme/setup#named-themes) to get started.

## Known Issues

- 🐞 **React 19 only**: `@wondesign/theme` needs React 19 or later
- 🐞 **light-dark() colors in Next.js**: Colors built with `light-dark()` may not follow the theme, or fall back to an unexpected color, when your build tool rewrites `light-dark()` for older browsers. See [Troubleshooting](/foundations/theme/troubleshooting) for the fix
