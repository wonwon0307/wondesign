```bash
pnpm add @wondesign/icons
```

<Callout variant="warning" title="Requires React 19">

## Key Features

- ✅ **Built with svg2tsx**: Generated from SVG files by [`@wondesign/svg2tsx`](/foundations/svg2tsx), as a [facade component](/foundations/svg2tsx/facade)
- ✅ **One Component**: Render any icon by its name, with `AppIcon`
- ✅ **Type-Safe Names**: Only real icon names are accepted, and the `IconName` type is exported for your own props
- ✅ **Fits the Text**: Icons take the size and color of the text around them by default

<Preview orientation="horizontal">
  <AppIcon icon="check-circle" />
  <AppIcon icon="warning" size={24} />
  <AppIcon icon="palette" size={32} color="purple" />
</Preview>

```tsx
import { AppIcon } from "@wondesign/icons";

// the size and color of the text around it
<AppIcon icon="check-circle" />

// a size in pixels
<AppIcon icon="warning" size={24} />

// a size and a color of your own
<AppIcon icon="palette" size={32} color="purple" />
```

## API

Import `AppIcon` and its types from `@wondesign/icons`:

```ts
import { AppIcon, type IconName, type IconProps } from "@wondesign/icons";
```

### Props

Accepts all props of `<svg>`, plus its own `icon` and `size`. Together, the
key props are:

```ts
interface AppIconProps extends IconProps {
  // the icon's name, from the list below.
  icon: IconName;

  // the width and height. a number is in pixels.
  // defaults to `"1em"`, the font size of the text around it.
  size?: number | string;

  // the icon's color. defaults to the color of the text around it.
  color?: string;

  // ...
}
```

- 📌 **An unknown name renders nothing**, with a warning in the console. The
  types catch it, unless the name comes from untyped data.
