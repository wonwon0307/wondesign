# API

This page covers every part of `Tabs`, its hooks and its types. Import them
from `@wondesign/headless/Tabs`:

```ts
import {
  // compound component, with its parts attached
  Tabs,
  // hooks
  useTabs,
  useTabsList,
  // named exports
  TabsProvider,
  TabsList,
  Tab,
  TabPanel,
  // types
  type TabsProps,
  type TabsListProps,
  type TabProps,
  type TabPanelProps,
} from "@wondesign/headless/Tabs";
```

---

## Components

The parts that make up `Tabs`. Each one, apart from the provider, renders a
single element and accepts that element's props. Every part must be inside the
provider.

### Provider

`Tabs` or `TabsProvider`. Coordinates every part: it holds the selected tab,
gives each tab and panel the ids that link them, and passes shared settings like
`isDisabled`, `switchOnFocus` and `keepPanelsMounted` down to them. Renders no
element of its own.

**Props**

```ts
interface TabsProps {
  children: React.ReactNode;
  defaultTab?: string; // defaults to the first enabled tab
  selectedTab?: string;
  onTabChange?: (tab: string) => void;
  isDisabled?: boolean; // defaults to `false`, disables every tab
  switchOnFocus?: boolean; // defaults to `false`
  keepPanelsMounted?: boolean; // defaults to `false`
}
```

### List

`Tabs.List` or `TabsList`. Renders a `<div>` that groups the tabs.

**Props**

Accepts all `<div>` props, except `role` and `aria-orientation`, which the list
manages. It sets its own `ref`, so it doesn't take one.

It also adds two props of its own. `vertical` marks the list as vertical, so
the up and down arrow keys move between tabs instead of left and right. It
doesn't change the layout; style that yourself with `data-orientation`, or the
`orientation` from the [`useTabsList`](#usetabslist) hook. `loop`
lets the arrow keys wrap around from the last tab to the first, instead of
stopping at the ends. Key props:

```ts
interface TabsListProps {
  children: React.ReactNode;
  asChild?: boolean;
  vertical?: boolean; // defaults to `false`
  loop?: boolean; // defaults to `false`
  // ...
}
```

**Data Attributes**

```ts
"data-orientation": "horizontal" | "vertical";
"data-disabled": "true" | undefined; // present when the tabs are disabled
```

### Tab

`Tabs.Tab` or `Tab`. Renders a `<button>` that selects its panel. Must be used
inside `Tabs.List`.

**Props**

Accepts all props of [Headless Button](/components/headless/button), except
`id`, `role`, `tabIndex`, `onClick`, `onFocus`, `aria-selected`,
`aria-controls` and `isLoading`, which the tab manages. You can also pass a `ref`; the tab sets
none of its own.

It also adds a prop of its own. `tabName` is required, and names the tab: it
pairs the tab with the panel of the same `tabName`, and it's the value you get
from `onTabChange`, `useTabs` and `data-value`. Key props:

```ts
interface TabProps {
  children: React.ReactNode;
  tabName: string; // matches its panel's `tabName`
  asChild?: boolean;
  isDisabled?: boolean; // defaults to `false`
  // ...
}
```

> When using `asChild` on a tab, render a `<button>` (or a component that renders one).
> Otherwise, keyboard and screen reader support could be lost silently.

**Data Attributes**

```ts
"data-state": "active" | "inactive";
"data-orientation": "horizontal" | "vertical";
"data-value": string; // the tab's `tabName`
"data-disabled": "true" | undefined; // present when disabled
```

### Panel

`Tabs.Panel` or `TabPanel`. Renders a `<div>` shown for its tab.

**Props**

Accepts all `<div>` props, except `id`, `role`, `hidden`, `tabIndex`,
`aria-hidden` and `aria-labelledby`, which the panel manages. You can also pass a `ref`; the
panel sets none of its own.

It also adds a prop of its own. `tabName` is required, and pairs the panel with
the tab of the same `tabName`: the panel is shown while that tab is selected.
Key props:

```ts
interface TabPanelProps {
  children: React.ReactNode;
  tabName: string; // matches its tab's `tabName`
  asChild?: boolean;
  // ...
}
```

**Data Attributes**

```ts
"data-state": "active" | "inactive";
```

## Hooks

Hooks read the state of the nearest provider or list, for building your own
parts. They throw an error when used outside one.

### useTabs

Reads the state of the nearest `Tabs`.

**Returns**

```ts
function useTabs(): {
  activeTab: string; // the selected tab's `tabName`
  updateActiveTab: (tab: string) => void; // selects a tab
  isDisabled: boolean; // whether every tab is disabled
};
```

### useTabsList

Reads the state of the nearest `Tabs.List`.

**Returns**

```ts
function useTabsList(): {
  orientation: "horizontal" | "vertical";
};
```
