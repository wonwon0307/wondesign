# AsChild

Every headless component renders a default element, like a `<button>` or a
`<nav>`. With `asChild`, you swap it for your own element and keep all of the
component's behaviour.

```tsx
import Link from "next/link";
import { Button } from "@wondesign/headless/Button";

<Button asChild>
  <Link href="/pricing">See pricing</Link>
</Button>;
```

See [Usage](/components/headless/as-child/usage) for the two ways to use it, and
[Guides](/components/headless/as-child/guides) for how your props and the
component's work together.

---

## Key Features

- ✅ **Keep the Behaviour**: Your element gets the component's ARIA attributes, state and handlers
- ✅ **Bring Any Element**: Native elements, router links, or your own components
- ✅ **Nothing Gets Lost**: Classes, styles and event handlers from both sides are combined

---

## Limitations

- ⚠️ **Refs aren't merged**: Unlike other props, only one `ref` reaches your
  element. If the component sets a ref, **it replaces the one on your child**.

  ```tsx
  // ✅ good - recommended method
  <Collapsible.Content asChild ref={ref}>
    <section>…</section>
  </Collapsible.Content>

  // ✅ good - Collapsible.Content sets no ref of its own
  <Collapsible.Content asChild>
    <section ref={ref}>…</section>
  </Collapsible.Content>

  // ❌ bad - <button>'s ref is ignored, because Tooltip.Trigger sets its own
  <Tooltip.Trigger asChild>
    <button ref={ref}>Help</button>
  </Tooltip.Trigger>
  ```

  See [How Props Combine](/components/headless/as-child/guides#how-props-combine)
  for how every other prop is handled.

- ⚠️ **One element only**: The child must be a single element. Text or several
  children **render nothing**, with a warning in development.

  ```tsx
  // ✅ good
  <Button asChild>
    <a href="/pricing">See pricing</a>
  </Button>

  // ❌ bad - two children, so nothing renders
  <Button asChild>
    <Icon />
    <span>See pricing</span>
  </Button>
  ```

  The single element can be your own component too. See
  [Components as the Child](/components/headless/as-child/guides#components-as-the-child)
  for what it needs.

---

## Supported Components

- 🔘 **[Button](/components/headless/button)**
- 🧩 **[Collapsible](/components/headless/collapsible)**: `Collapsible.Toggle`,
  `Collapsible.Content`
- 🧩 **[Tabs](/components/headless/tabs)**: `Tabs.List`, `Tabs.Tab`, `Tabs.Panel`
- 🧩 **[Tooltip](/components/headless/tooltip)**: `Tooltip.Trigger`,
  `Tooltip.Content`
- 🧩 **[Navbar](/components/headless/navbar)**: `Navbar`, `Navbar.List`,
  `Navbar.Item`

`Anchor`, and every component built on it, take an `as` prop instead, for rendering a router
link. See the [Anchor](/components/headless/anchor#router-links) document for details.
