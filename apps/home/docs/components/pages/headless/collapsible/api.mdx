# API

This page covers every part of `Collapsible`, its hook and its types. Import
them from `@wondesign/headless/Collapsible`:

```ts
import {
  // compound component, with its parts attached
  Collapsible,
  // hook
  useCollapsible,
  // named exports
  CollapsibleProvider,
  CollapsibleToggle,
  CollapsibleContent,
  // types
  type CollapsibleProps,
  type CollapsibleToggleProps,
  type CollapsibleContentProps,
} from "@wondesign/headless/Collapsible";
```

---

## Components

The parts that make up a `Collapsible`. Each one, apart from the provider,
renders a single element and accepts that element's props. Every part must be
inside the provider.

### Provider

`Collapsible` or `CollapsibleProvider`. Coordinates every part: it holds the
open state, gives the toggle and content the ids that link them, and passes
shared settings like `keepMounted` down to them. Renders no element of its own.

**Props**

```ts
interface CollapsibleProps {
  children: React.ReactNode;
  isOpen?: boolean;
  onOpenChange?: (open: boolean) => void;
  defaultOpen?: boolean; // defaults to `false`
  keepMounted?: boolean; // defaults to `false`
}
```

### Toggle

`Collapsible.Toggle` or `CollapsibleToggle`. Renders a `<button>` that opens
and closes the content.

**Props**

Accepts all props of [Headless Button](/components/headless/button), except
`id`, `onClick`, `aria-expanded` and `aria-controls`, which the toggle manages.
You can also pass a `ref`; the toggle sets none of its own. Key props:

```ts
interface CollapsibleToggleProps {
  asChild?: boolean;
  isDisabled?: boolean; // defaults to `false`
  isLoading?: boolean; // defaults to `false`
  // ...
}
```

> When using `asChild` on the toggle, render a `<button>` (or a component that renders one).
> Otherwise, keyboard and screen reader support could be lost silently.

**Data Attributes**

```ts
"data-state": "open" | "closed";
"data-disabled": "true" | undefined; // present when disabled
"data-loading": "true" | undefined; // present when loading
```

### Content

`Collapsible.Content` or `CollapsibleContent`. Renders a `<div>` that's shown
and hidden.

**Props**

Accepts all `<div>` props, except `id`, `hidden`, `aria-hidden` and
`aria-labelledby`, which the content manages. You can also pass a `ref`; the
content sets none of its own.

It also narrows `role` to `"group"` or `"region"`. It's a `group` by default;
pass `"region"` when the content is a major section of the page, and it's
labelled by its toggle. Key props:

```ts
interface CollapsibleContentProps {
  children: React.ReactNode;
  asChild?: boolean;
  role?: "group" | "region"; // defaults to `"group"`, or none with `asChild`
  // ...
}
```

**Data Attributes**

```ts
"data-state": "open" | "closed";
```

## Hooks

Hooks read the state of the nearest provider, for building your own parts.
They throw an error when used outside one.

### useCollapsible

Reads the open state of the nearest `Collapsible`.

**Returns**

```ts
function useCollapsible(): {
  isOpen: boolean; // whether the content is open
  toggle: () => void; // opens or closes the content
};
```
