# Usage

This page covers what you can configure on `Anchor`. For every prop, refer to
the [API tab](/components/headless/anchor/api).

To see real, styled examples of `Anchor`, go to the
[Examples tab](/components/links/anchor/examples) of `Anchor` in
`@wondesign/links`.

---

## Opening in a New Tab

Override which links open in a new tab with `openInNewTab`. `target` and `rel`
**aren't accepted**, so `openInNewTab` is the only way to control it:

```tsx
// external, opens in a new tab
<Anchor href="https://github.com/wonwon0307">GitHub</Anchor>

// internal, opens in the current tab
<Anchor href="/docs">Docs</Anchor>

// external, but stays in the current tab
<Anchor href="https://github.com/wonwon0307" openInNewTab={false}>
  GitHub
</Anchor>

// internal, but opens in a new tab
<Anchor href="/docs" openInNewTab>
  Docs
</Anchor>
```

## Router Links

Pass your router's link component to `as`, and it renders that instead of a
plain `<a>`, with all of `Anchor`'s behaviour:

```tsx
import Link from "next/link";

<Anchor as={Link} href="/pricing">
  Pricing
</Anchor>;
```

`Anchor` swaps its element with `as`, not `asChild`. It can still be the child
of another component's `asChild`, like a
[Tooltip.Trigger](/components/headless/as-child/usage#rendering-a-link).

---

## Disabled

Pass `isDisabled` to turn the link off, instead of passing `href={null}`:

```tsx
<Anchor href="/billing" isDisabled>
  Billing
</Anchor>
```

## Styling with Data Attributes

Style it with `className` and `style`. Its states show up as
[data attributes](/components/headless/anchor/api#data-attributes):

```css
.link[data-disabled] { … }
.link[data-external] { … }
.link[data-new-tab] { … }
```
