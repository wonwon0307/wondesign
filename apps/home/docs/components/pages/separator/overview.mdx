  `@wondesign/separator` is the separator of WonDesign Components. Its
  `Separator` component draws a thin line between pieces of content, horizontal

  real break in the page.


## Key Features

- ✅ **Two Orientations**: Divide content stacked on top of each other, or placed side by side
- ✅ **Two Weights**: A regular line, or a bold one for stronger breaks
- ✅ **Decorative or Semantic**: Hidden from screen readers when it's only for looks, announced when it's a real break
- ✅ **Fills Its Container**: Stretches to the full width or height of the space it's in

## API

Import `Separator` and its props type from `@wondesign/separator`:

```ts
import { Separator, type SeparatorProps } from "@wondesign/separator";
```

### Props

Accepts the props of `<div>`, except `children`. It also leaves out `role`,
`aria-hidden` and `aria-orientation`, which it sets from `variant` and
`vertical`. Together, the separator props are:

```ts
interface SeparatorProps {
  // whether the line is for looks only, or a real break. defaults to `"decorative"`.
  variant?: "decorative" | "theme-break";

  // draws a vertical line instead of a horizontal one. defaults to `false`.
  vertical?: boolean;

  // draws a 2px line instead of a 1px one. defaults to `false`.
  bold?: boolean;

  // ...
}
```
