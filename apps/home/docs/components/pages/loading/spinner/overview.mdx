# Spinner

`Spinner` renders a spinning icon, for an action in progress, like saving a
form or loading a list. It's sized to the text around it, so it fits next to
a label or inside a button.

---

## Key Features

- ✅ **Four Styles**: Pick the spinner that fits your design
- ✅ **Matches Its Text**: Takes the size and color of the text around it
- ✅ **Three Speeds**: Slow, normal and fast
- ✅ **Respects Reduced Motion**: Spins slower when the user asks for less motion

## API

Import `Spinner` and its props type from `@wondesign/loading/Spinner`:

```ts
import { Spinner, type SpinnerProps } from "@wondesign/loading/Spinner";
```

### Props

Renders an `<svg>`. Accepts all `<svg>` props except `aria-hidden`, plus its
own `appearance`, `size` and `speed`. `aria-hidden` **isn't accepted**, since
the spinner is always hidden from screen readers. Together, the key props
are:

```ts
interface SpinnerProps {
  // the spinner's style. defaults to `"default"`.
  appearance?: "default" | "tail" | "line" | "bubble";

  // the width and height. any CSS length, or a number in pixels.
  // defaults to `"1.25em"`, which follows the font size around it.
  size?: number | string;

  // how fast it spins. defaults to `"normal"`.
  speed?: "slow" | "normal" | "fast";

  // ...
}
```

---

## Watch Out

- ⚠️ **Mark what's loading yourself**: **Screen readers don't announce the
  spinner**. Use `aria-busy` or loading text. See
  [Accessibility](/components/loading/spinner/examples#accessibility).
