# Examples

Common ways to use `Anchor`, from turning a link off to styling your own
link. Each example shows the rendered result, followed by its code.

---

## External and Router Links

`Anchor` opens links to other sites in a new tab, and renders your router's
link component with `as`, the same way as the headless `Anchor`. See
[Opening in a New Tab](/components/headless/anchor/usage#opening-in-a-new-tab)
and [Router Links](/components/headless/anchor/usage#router-links) in its
docs.

---

## Disabled

Pass `isDisabled` to turn the link off. It can't be followed, it leaves the
tab order, and the cursor turns into a not-allowed cursor:

<Preview>
  <Anchor
    href="#"
    style={{
      display: "block",
      padding: "var(--spacing-lg)",
      border: "1px solid var(--color-border)",
      borderRadius: "var(--radius-md)",
    }}
  >
    <Heading level={4}>{"Links"}</Heading>
    <Description>{"Available"}</Description>
  </Anchor>
  <Anchor
    href="#"
    isDisabled
    style={{
      display: "block",
      padding: "var(--spacing-lg)",
      border: "1px solid var(--color-border)",
      borderRadius: "var(--radius-md)",
    }}
  >
    <Heading level={4}>{"Links"}</Heading>
    <Description>{"Disabled"}</Description>
  </Anchor>
</Preview>

```tsx
<Anchor href="/components/links" className="card">
  <Heading level={4}>Links</Heading>
  <Description>Available</Description>
</Anchor>

<Anchor href="/components/links" isDisabled className="card">
  <Heading level={4}>Links</Heading>
  <Description>Disabled</Description>
</Anchor>
```

- 📌 **The content doesn't look disabled.** Style it yourself with
  `[data-disabled]`.

---

## Styling

`Anchor` has no styles of its own beyond the focus outline and the disabled
cursor. Add your own with `className` or `style`, and style its states with
data attributes:

```tsx
<Anchor href={`/posts/${post.id}`} className="card">
  {children}
</Anchor>
```

```css
.card {
  padding: var(--spacing-lg);
  border: 1px solid var(--color-border);
}

.card[data-disabled] {
  opacity: 0.5;
}

.card[data-new-tab]::after {
  content: " ↗";
}
```

- 📌 **The focus outline has square corners**, even when your content is
  rounded. Set a `border-radius` on the `Anchor` to match its content.
