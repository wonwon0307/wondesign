# Examples

Common ways to use `IconLink`, from picking an icon to fitting it into your
own design. Each example shows the rendered result, followed by its code.
**Every link on this page takes you to the top of the page.**

---

## Icon or Children

Pass an `icon` name from [`@wondesign/icons`](/components/icons#icon-list),
or your own content as `children`, like a logo:

<Preview orientation="horizontal">
  <IconLink icon="download" href="#" aria-label="Download" />
  <IconLink href="#" aria-label="GitHub">
    <GithubLogo size="1em" />
  </IconLink>
</Preview>

```tsx
<IconLink icon="download" href="/files/guide.pdf" aria-label="Download" />

<IconLink href="https://github.com/wonwon0307" aria-label="GitHub">
  <GithubLogo />
</IconLink>
```

- 📌 It's strongly recommended to give every icon link an `aria-label`,
  like "Download" or "GitHub". Without one, its name won't tell screen
  reader users much about where it goes.

---

## Appearances

The `appearance` property sets how much the link stands out. `"outlined"` is
the default:

- 🎨 **`"filled"`**: a solid primary background, for the main link.
- 🎨 **`"outlined"`**: a border, with a background on hover.
- 🎨 **`"ghost"`**: no border or background until hovered, for toolbars,
  headers and footers.

<Preview orientation="horizontal">
  <IconLink icon="download" appearance="filled" href="#" aria-label="Download" />
  <IconLink icon="download" appearance="outlined" href="#" aria-label="Download" />
  <IconLink icon="download" appearance="ghost" href="#" aria-label="Download" />
</Preview>

```tsx
<IconLink icon="download" appearance="filled" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" appearance="outlined" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" appearance="ghost" href="/files/guide.pdf" aria-label="Download" />
```

## Sizes

The `size` property sets the size of the icon, as any CSS length, or a
number in pixels. `"1em"` is the default, so the icon follows the font size
around it:

<Preview orientation="horizontal">
  <IconLink icon="download" href="#" aria-label="Download" />
  <IconLink icon="download" size={24} href="#" aria-label="Download" />
  <IconLink icon="download" size="2rem" href="#" aria-label="Download" />
</Preview>

```tsx
<IconLink icon="download" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" size={24} href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" size="2rem" href="/files/guide.pdf" aria-label="Download" />
```

- 📌 **`size` is ignored with `children`.** Size your own content yourself.

## Rounded

Pass `rounded` to make the link a circle:

<Preview orientation="horizontal">
  <IconLink icon="download" href="#" aria-label="Download" />
  <IconLink icon="download" rounded href="#" aria-label="Download" />
</Preview>

```tsx
<IconLink icon="download" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" rounded href="/files/guide.pdf" aria-label="Download" />
```

---

## Spacious

Pass `spacious` to give the icon more room, for a larger click target or a
link that needs to stand out more:

<Preview orientation="horizontal">
  <IconLink icon="download" href="#" aria-label="Download" />
  <IconLink icon="download" spacious href="#" aria-label="Download" />
</Preview>

```tsx
<IconLink icon="download" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" spacious href="/files/guide.pdf" aria-label="Download" />
```

It works well with larger icons, which look cramped in the default padding:

<Preview orientation="horizontal">
  <IconLink icon="download" size="2rem" href="#" aria-label="Download" />
  <IconLink icon="download" size="2rem" spacious href="#" aria-label="Download" />
</Preview>

```tsx
<IconLink icon="download" size="2rem" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" size="2rem" spacious href="/files/guide.pdf" aria-label="Download" />
```

---

## Disabled

Pass `isDisabled` to turn the link off. It can't be followed, leaves the tab
order, and fades:

<Preview orientation="horizontal">
  <IconLink icon="download" href="#" aria-label="Download" />
  <IconLink icon="download" isDisabled href="#" aria-label="Download" />
</Preview>

```tsx
<IconLink icon="download" href="/files/guide.pdf" aria-label="Download" />
<IconLink icon="download" isDisabled href="/files/guide.pdf" aria-label="Download" />
```

---

## Styling

When a single link needs to look different, change it with `className` or
`style`, like a different icon color:

<Preview orientation="horizontal">
  <IconLink
    icon="download"
    href="#"
    aria-label="Download"
    style={{ color: "var(--color-primary)" }}
  />
</Preview>

```tsx
<IconLink
  icon="download"
  href="/files/guide.pdf"
  aria-label="Download"
  style={{ color: tokens.colors.primary }}
/>
```
