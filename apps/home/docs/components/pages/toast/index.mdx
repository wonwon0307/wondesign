  `@wondesign/toast` shows short messages with a single function call, from
  anywhere in your app, like "Saved" or "Link copied". Toasts close on their

## Key Features

- ✅ **Ready to Use**: Show a toast with one function call, with no state to manage
- ✅ **Status Types**: Show info, success, warning and error toasts
- ✅ **Composable**: Render every toast with your own component, and keep the same functions
- ✅ **Your Own Toaster**: Or keep only the list of toasts, and render it your own way
- ✅ **Accessible by Default**: Announced to screen readers without moving focus

Use it for messages that don't need an answer. For messages the user has to
answer before they carry on, **use an [Alert](/components/alert) instead**.

---

## Entry Points

The package comes with two entry points. Both share the same list of toasts.

- ⭐ **[Toaster](/components/toast/toaster)** — `@wondesign/toast`. A
  ready-made `Toaster` and a `toast` function, with types, positions and
  actions. Start here.
- ⭐ **[Base](/components/toast/base)** — `@wondesign/toast/base`. Only the
  list of toasts and the functions to change it, with nothing rendered. Use it
  to build your own Toaster.
