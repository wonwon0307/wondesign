## Key Features

- ✅ **Elements**: Each renders a fitting native element, can render another with `as`, and passes your `ref` to it
- ✅ **Blocks**: Ready-made components for common text patterns, like callouts and badges
- ✅ **Consistent Text**: The same kind of text looks and behaves the same across your app, instead of a mix of `<h1>`–`<h6>`,
  `<div>`s and `<span>`s, each styled its own way
- ✅ **On the Type Scale**: Sizes, weights and line heights come from the design tokens
- ✅ **Styleable**: Your `className` and `style` are applied on top of the defaults

## Components

The components come in two kinds: elements, and blocks. Both read their
values from `@wondesign/tokens`, and fall back to the default values without
the token stylesheet.

### Elements

Single pieces of text, each rendering one native element. Use them for every
title and body of text, so the same kind of text always renders the same way.

- ⭐ **[Heading](/components/texts/heading)** — a page or section title, from
  `<h1>` to `<h6>`, kept to a single line by default.
- ⭐ **[Description](/components/texts/description)** — supporting text, like
  a summary of the whole page right below its `Heading`, a field hint, a
  caption or a metadata value.
- ⭐ **[Paragraph](/components/texts/paragraph)** — the main body text of a
  page, a section or a card, from a single sentence to several paragraphs.

### Blocks

Text styled for a specific job, with its own layout and colors. Use them for
patterns that show up across many pages.

- ⭐ **[Callout](/components/texts/callout)** — a highlighted note with an
  icon and an optional title, for information, warnings, errors or successes.
- ⭐ **[Badge](/components/texts/badge)** — a short label in a colored pill,
  like a status, a category or a count.

## Upcoming Features

- 🔜 **Heading Weight**: Override a heading's font weight, independent of its level
- 🔜 **Eyebrow**: A short line above a heading, like "Pricing" above "Plans for every team"
- 🔜 **Paragraph Wrapping**: Choose how a paragraph's lines wrap, like balancing them, as a Description can
- 🔜 **Line Length Presets**: Cap a paragraph or description at a narrow, default or wide line length, for easier reading
- 🔜 **Expandable Paragraph**: Cut a long paragraph off after a few lines, with a button to show the rest
- 🔜 **Drop Cap**: Start a paragraph with an enlarged first letter, for long-form reading
- 🔜 **Quote**: A quotation, with an optional source
- 🔜 **Description List**: Pairs of terms and values, like "Status: Active" or "Created: Oct 26"
- 🔜 **Stat**: A large number with a label, and its change shown in a Badge, like "1,204 active users, +12%"
