# InlineCode

`InlineCode` renders a short piece of code within a sentence, like a prop
name, a file path or a command. It renders a `<code>` element in the code
font, with a muted background that sets it apart from the text around it.

---

## Key Features

- ✅ **Three Sizes**: Small, medium and large, to match the text around it
- ✅ **Fits the Text**: Takes the color of the text around it
- ✅ **Wraps Long Code**: Long paths and URLs wrap, instead of running past the edge
- ✅ **Ref Forwarding**: Your `ref` reaches the rendered element

## API

Import `InlineCode` and its props type from `@wondesign/code/InlineCode`:

```ts
import { InlineCode, type InlineCodeProps } from "@wondesign/code/InlineCode";
```

### Props

Accepts all props of `<code>`, plus its own `size`. Your `ref` reaches the
rendered `<code>` element. Together, the key props are:

```ts
interface InlineCodeProps {
  children: React.ReactNode;

  // the font size and padding. defaults to `"medium"`.
  size?: "small" | "medium" | "large";

  ref?: React.Ref<HTMLElement>;

  // ...
}
```

---

## Watch Out

- ⚠️ **Keep inline code short**: Long code, like a file path or a URL, wraps
  as one block inside its own background, **instead of flowing with the
  sentence**.
