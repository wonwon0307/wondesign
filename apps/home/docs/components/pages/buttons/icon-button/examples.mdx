# Examples

Common ways to use `IconButton`, from picking an icon to fitting it into your
own design. Each example shows the rendered result, followed by its code.

---

## Icon or Children

Pass an `icon` name from [`@wondesign/icons`](/components/icons#icon-list),
or your own content as `children`, like a logo:

<Preview orientation="horizontal">
  <IconButton icon="copy" aria-label="Copy" />
  <IconButton aria-label="GitHub">
    <GithubLogo size="1em" />
  </IconButton>
</Preview>

```tsx
<IconButton icon="copy" aria-label="Copy" />

<IconButton aria-label="GitHub">
  <GithubLogo />
</IconButton>
```

- 📌 It's strongly recommended to give every icon button an `aria-label`,
  like "Copy" or "GitHub". Without one, its name won't tell screen reader
  users much about what it does.

---

## Variants

The `variant` property sets how much the button stands out. `"outlined"` is
the default:

- 🎨 **`"filled"`**: a solid primary background, for the main action.
- 🎨 **`"outlined"`**: a border, with a background on hover.
- 🎨 **`"ghost"`**: no border or background until hovered, for toolbars and
  headers.

<Preview orientation="horizontal">
  <IconButton icon="copy" variant="filled" aria-label="Copy" />
  <IconButton icon="copy" variant="outlined" aria-label="Copy" />
  <IconButton icon="copy" variant="ghost" aria-label="Copy" />
</Preview>

```tsx
<IconButton icon="copy" variant="filled" aria-label="Copy" />
<IconButton icon="copy" variant="outlined" aria-label="Copy" />
<IconButton icon="copy" variant="ghost" aria-label="Copy" />
```

---

## Sizes

The `size` property sets the size of the icon, as any CSS length, or a
number in pixels. `"1em"` is the default, so the icon follows the font size
around it:

<Preview orientation="horizontal">
  <IconButton icon="copy" aria-label="Copy" />
  <IconButton icon="copy" size={24} aria-label="Copy" />
  <IconButton icon="copy" size="2rem" aria-label="Copy" />
</Preview>

```tsx
<IconButton icon="copy" aria-label="Copy" />
<IconButton icon="copy" size={24} aria-label="Copy" />
<IconButton icon="copy" size="2rem" aria-label="Copy" />
```

- 📌 **`size` is ignored with `children`.** Size your own content yourself.

## Spacious

Pass `spacious` to give the icon more room, for a larger click target or a
button that needs to stand out more:

<Preview orientation="horizontal">
  <IconButton icon="copy" aria-label="Copy" />
  <IconButton icon="copy" spacious aria-label="Copy" />
</Preview>

```tsx
<IconButton icon="copy" aria-label="Copy" />
<IconButton icon="copy" spacious aria-label="Copy" />
```

It works well with larger icons, which look cramped in the default padding:

<Preview orientation="horizontal">
  <IconButton icon="copy" size="2rem" aria-label="Copy" />
  <IconButton icon="copy" size="2rem" spacious aria-label="Copy" />
</Preview>

```tsx
<IconButton icon="copy" size="2rem" aria-label="Copy" />
<IconButton icon="copy" size="2rem" spacious aria-label="Copy" />
```

## Loading

Pass `isLoading` while an action is in progress. Presses are blocked, screen
readers announce the button as busy, and a
[Spinner](/components/loading/spinner) the size of the icon takes its place.
**The button keeps its size**, so the layout around it doesn't move:

<Preview orientation="horizontal">
  <IconButton icon="upload" aria-label="Upload" />
  <IconButton icon="upload" isLoading aria-label="Upload" />
</Preview>

```tsx
<IconButton
  icon="upload"
  isLoading={isUploading}
  onClick={upload}
  aria-label="Upload"
/>
```

### Custom Fallback

Pass `fallback` to show your own content instead of the default spinner,
like a different spinner variant:

<Preview orientation="horizontal">
  <IconButton
    icon="upload"
    isLoading
    fallback={<Spinner variant="tail" size="1em" />}
    aria-label="Upload"
  />
</Preview>

```tsx
import { Spinner } from "@wondesign/loading/Spinner";

<IconButton
  icon="upload"
  isLoading
  fallback={<Spinner variant="tail" size="1em" />}
  aria-label="Upload"
/>;
```

- 📌 **A custom fallback isn't sized for you.** Set its size to match the
  icon, or it may be larger than the button's content.

## Styling

When a single button needs to look different, change it with `className` or
`style`, like a different icon color:

<Preview orientation="horizontal">
  <IconButton
    icon="copy"
    aria-label="Copy"
    style={{ color: "var(--color-primary)" }}
  />
</Preview>

```tsx
<IconButton
  icon="copy"
  aria-label="Copy"
  style={{ color: tokens.colors.primary }}
/>
```
