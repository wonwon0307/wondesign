# IconButton

`IconButton` builds on [Pressable](/components/buttons/pressable) to render a
compact button with a single icon, like a copy or close button. Pass an icon
name from [`@wondesign/icons`](/components/icons), or your own content.

---

## Key Features

- ✅ **Built-in Icons**: Pass an icon name, and the icon is rendered for you
- ✅ **Your Own Content**: Or pass any content, like your own icon
- ✅ **Three Variants**: Filled, outlined or ghost, for how much the button stands out
- ✅ **Any Size**: Follows the text around it, or takes the size you set
- ✅ **Rounded or Spacious**: Make the button a circle, or give the icon more room
- ✅ **Loading Spinner**: Shows a spinner while loading, without changing the button's size

```tsx
import { IconButton } from "@wondesign/buttons/IconButton";

<IconButton icon="copy" aria-label="Copy" onClick={copy} />;
```

See [Examples](/components/buttons/icon-button/examples) for icons,
variants, sizes, rounded and spacious buttons, loading and styling.

## API

Import `IconButton` and its props type from `@wondesign/buttons/IconButton`:

```ts
import { IconButton, type IconButtonProps } from "@wondesign/buttons/IconButton";
```

### Props

Accepts all props of [Pressable](/components/buttons/pressable#props), plus
its own `variant`, `size`, `rounded`, `spacious` and `fallback`, and either
`icon` or `children`.
Passing both is a type error. Together, the key props are:

```ts
type IconButtonProps = {
  // the look. defaults to `"outlined"`.
  variant?: "filled" | "outlined" | "ghost";

  // the size of the icon. any CSS length, or a number in pixels.
  // defaults to `"1em"`. ignored with `children`.
  size?: number | string;

  // a circle instead of rounded corners. defaults to `false`.
  rounded?: boolean;

  // wider padding around the icon. defaults to `false`.
  spacious?: boolean;

  // shown in place of the content while `isLoading` is set.
  // defaults to a `Spinner` the size of the icon.
  fallback?: React.ReactNode;

  // ...
} & (
  | {
      // an icon name from `@wondesign/icons`.
      icon: IconName;
    }
  | {
      // your own content, in place of an icon.
      children: React.ReactNode;
    }
);
```
